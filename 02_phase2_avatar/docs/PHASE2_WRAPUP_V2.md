## 二、灰阶方块 v5

### 你那条"极端明度下饱和度不敏感"直接改变了结果

```
effective_sat = sat × (0.25 + 0.75 × (1 − |grey−127.5|/127.5))
```

灰 11 处饱和度只按 25% 计，所以 **`black_concrete`（饱和度 0.454，偏蓝）在等级 0 变成最优选**——
这在灰 11 上确实看不出蓝。中灰区仍然全额惩罚饱和度。

### 我找到了"颜色方差"的真正含义

你说基岩和高炉的方差大，但**闪长岩的贴图内部方差是 34.7，比基岩 38.0 还接近**，而你认可了闪长岩。
所以"方差"不是贴图内部噪声。测**分面之间**的平均色差异，立刻对上了：

| 方块 | 分面间差异 | 各分面灰度 |
|---|---:|---|
| **blast_furnace** | **12.66** | 81 / 107 / 108 |
| **bone_block** | 11.29 | 198 / 221 |
| diorite（你认可） | **0.00** | 189 |
| andesite（你认可） | 0.00 | 136 |

**高炉三种分面差别明显**（正面暗），做单像素会在不同角度变色。现在用 `face_var ≤ 3` 硬过滤。

### 活塞限制

`bedrock` 直接不可推动；Java 版里**带方块实体的方块也不能被活塞推动**，所以 `blast_furnace`、
熔炉、箱子、漏斗、潜影盒全部排除。**你这两条判断都是对的。**

### 台阶与门

**台阶放行**（两个能合成整方块），门/活板门/栅栏/玻璃板**排除**（填不满格子）。
