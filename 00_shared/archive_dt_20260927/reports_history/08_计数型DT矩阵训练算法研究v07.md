# D/T Count 训练算法研究 v0.7

## 核心结论

1. 当前最有效的新组合是 **data curriculum + whole-node block cleanup**。在 4 输入、h=12 的函数级 K<=4 Count 上，MLP Teacher 从旧基线 5257 错改善到 4999 错；Count Teacher 曾出现 346/65536 错的极佳轨迹。
2. 但 346 错不是稳定水平。额外 16 个独立 restart 中，最好只有 3043 错，中位数约 10862 错，证明搜索分布具有明显重尾/局部最优问题。
3. 保函数扩宽、贪心逐节点 growth、节点 crossover、弱节点 rejuvenation 都没有解决稳定性；它们更适合作为初始化/辅助方法。
4. OneFlip 的 soft-to-hard 仍是主瓶颈。alpha blending、深层 OneFlip、蒸馏都没有超过 v06 的 anneal 基线；增加隐藏层在当前量化训练下反而更难。
5. 按 Differentiable Logic Gate Network 思路做的 naive function-library soft categorical K=1/2 也不够强，说明不能只把全部离散函数塞进 softmax 就期待自动学好。
6. 下一优先方案：**adaptive flip-gate / Hard-Concrete Count**。每条一维二值边用初始位+15个翻转开关表示，并用可微 flip gates + L0 稀疏惩罚自动学习每条边需要多少次反转。这统一 OneFlip、K2、K4，而无需预先固定 K。
7. 另一优先方案：**learnable sparse connectivity**。参考 2026 Fully Trainable LGN/LUTN 与 DiffLUT-Net，把输入来源选择也作为可学习离散变量；这同时降低训练维度、Minecraft fanout 和布线体积。

## 方法状态

- Data curriculum: 有效，保留。
- Whole-node block proposals: 有效，保留。
- 多 restart: 必需，但成本线性增长，且好解概率仍偏低。
- Function-preserving growth: 单独无效；后续若再用，应加入 residual/差异化节点初始化。
- Greedy growth: 便宜但弱，可作初始化器。
- Population node crossover: 未显示优势。
- Rejuvenation/trimming weak nodes: 当前定义下基本无效。
- Simulated annealing: naive full-state evaluation 成本过高，本轮未形成可用结果。
- Alpha blending: 没解决 OneFlip 的 4 输入 hard mismatch。
- Distillation: 没解决 OneFlip hard mismatch。
- Naive differentiable function library: K1/K2 pilot 不如函数级坐标下降。

## 研究启发

现实离散网络中最可迁移的不是某一个优化器，而是三类设计：

1. gate/LUT function relaxation + hard deployment；
2. learnable sparse connectivity / stochastic gates；
3. progressive growth/quantization，并明确处理 train-deploy mismatch。

我们的下一版训练器应把“函数复杂度”和“连接稀疏度”都变成可学习且可惩罚的变量，而不是继续固定 K 后在巨大离散表空间中做局部 bit flip。
