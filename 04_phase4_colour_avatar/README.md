## 三条贯穿全项目的结论（先记住这三条，能省很多弯路）

1. **强模 → 生存模式造不出来。** 已完成的实物全是强模网络。价值在"证明这也能算"，不在"这能用"。
2. **红石的成本由"输出要不要各自成一条通路"决定，不由网络多深决定。** 分类是收缩（225→10，一次聚合 + argmax），生成不是收缩（64 个输出像素各要一条聚合通路）。这是二期"生成比分类难"的结构性原因。
3. **指标会骗人。** 一期 MNIST 87.4% 的模型在粗笔画输入上掉到 24%；二期三次"预测良率 95%、实测 41%"。评估必须包含扰动测试与人的盲测。
