# 关键结论速查

## 强模 LUT

| 项 | 值 |
|---|---|
| 单元结构 | **固定 16 个容器**，每个容器恰好控制一个步长 |
| 容器内容 | $b\in[0,897]$ |
| 单步长 | $\lvert\Delta\lambda\rvert\le868$ |
| **$\lambda$ 上限** | $15\times897\approx13455$（**不是 897**） |
| $\lambda$ 非负 | **恒成立**（比较器不能输出负信号） |
| 步长公式 | $\lambda(x)=\mathrm{round}(x\rho)$（**浮动步长**，不取整斜率） |
| 逐坐标定步长 | $\rho_i=868\cdot\lvert w_i\rvert/\max_j\lvert w_j\rvert$ |
| **折叠阶梯** | 不折叠误差 58%，折叠后 **0.0035** |
| ReLU vs tanh | ReLU 错误率高 3.9 倍，但体积只 27% |

## 编译实测

| 任务 | 方案 | 指标 |
|---|---|---|
| $4\to8\to1$ tanh | 8 bit 拆分 | 错误 75/65536（**0.1144%**），176 单元 |
| $4\to8\to1$ ReLU | 8 bit 拆分 | 错误 294/65536（0.4486%），**48 单元** |
| 鸢尾花 3 分类 | 4 bit | 150 点 **0.9867**，**21 单元** |
| 鸢尾花 3 分类 | 8 bit | 150 点 **0.9933**，**30 单元** |

## MNIST（相关结论）

| 方案 | 参数 | 准确率 |
|---|---:|---:|
| **直接 225 像素 → 10 线性** | **2250** | **0.8915** |
| 全 1 卷积 + 三档阈值 $[1,4,9]$ | 6750 | 0.9069 |
| 全 1 卷积 + 两档阈值 $[1,5]$ | 4500 | 0.9007 |

**复杂的卷积管道只比直接线性多 1.5 个点。**

## 头像生成

| 项 | 值 |
|---|---|
| 最佳生成结果 | `02_phase2_avatar/archive_phase1_attempts/results/sym_sym_30_0.png`（完全对称 + $T=30$） |

# 一句话总结

> **强模 LUT 的数学是扎实的、经过数值验证的；但它做不出生存模式的电路，
> 而在能做的范围内（MNIST）它的收益又不足以抵消复杂度。
> 头像生成则卡在"能看的方案不可移植、可移植的方案不能看"。
> 两条线的共同瓶颈都是：缺少一个"辰占鳌头装置实测数据"作为比较基准。**
