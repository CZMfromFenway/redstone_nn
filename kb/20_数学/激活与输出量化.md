# 激活与输出：层出口的整数化

状态: 定案
可信度: 权威（三期编译定案文档），本页只做统一叙述
最后核实: 2026-10-31
适用: 整数化 MLP 的层出口；**两种矩阵乘法构型共用**；**层间默认走 RELU**，CLIP 只出现在需要保留完整量程的出口

---

## 引言

矩阵乘法部分交出的是**非负整数累加量** $N_j$ 与它的上界。它不能直接交给下一层：

- 量级可到几万，而下一层的入口只有固定档数；
- 它带着一个与输入无关的常数（偏置 + 阶梯初值）；
- “负的那一半”还没被划开——它不是不存在，而是**还没有零点**。

层出口只做两件事：**减零点、按开关压成整数输出**。两件事都与上游用哪种矩阵乘法无关。

> 写法约定：实数激活写小写 $\mathrm{relu}$，它的整数版写大写 $\mathrm{RELU}$。
> 两者不是同一个函数——$\mathrm{RELU}$ 是“减零点、除步长、夹位宽”之后的整数映射。

---

## 符号

按作者 2026-10-30 的修订：输出量化步长记 $\Gamma_j$（旧文 $c_j$/$s_j$ 混用），
CLIP 截断点记 $\Omega$（整数）与 $\omega$（实数），整数输出记 $Y_j$，
输入/输出分辨率分别记 $\delta_{X,i}$ 与 $\delta_{Y,j}$。

| 符号                   | 含义                                | 来源              |
| -------------------- | --------------------------------- | --------------- |
| $x_i$ / $X_i$        | 第 $i$ 个输入的实数 / 量化整数               | 继承              |
| $\delta_{X,i}$       | **输入**分辨率：$X_i$ 增 1 对应多少实数        | 继承              |
| $\delta_{Y,j}$       | **输出**分辨率：$Y_j$ 增 1 对应多少实数        | 交出              |
| $C_j$                | 原始累加（可负）                          | 继承              |
| $C_{j,\min}$         | 它的最小可能值                           | 继承              |
| $N_j=C_j-C_{j,\min}$ | 非负整数累加量                           | 继承              |
| $N_j^{\max}$         | 它的上界                              | 继承              |
| $\sigma_j$           | 缩放因子：预激活增 1，$N$ 增 $\sigma_j$      | 继承              |
| $\eta_j$             | 实数预激活，$y_j=\mathrm{relu}(\eta_j)$ | 中间量             |
| $P_j$                | **整数零点**                          | 本页求出            |
| $\Gamma_j$           | **输出量化步长**（每级多少个 $N$ 单位）          | 本页求出            |
| $\Omega$ / $\omega$  | CLIP 的整数 / 实数上界                   | 本页求出            |
| $Y_j$                | 整数输出                              | 交给下一层           |
| $b_Y$                | **本层输出位宽**                        | 本页选定，或称由下一层计划给定 |
| $b_X$                | 本层输入位宽（只作对照，不参与本页公式）              | 由上一层给定          |

$$\eta_j\approx\frac{N_j-P_j}{\sigma_j},\qquad y_j=\mathrm{relu}(\eta_j)$$

> **关于 $b$ 的一个界定。** 本页出现的位宽**一律是输出位宽 $b_Y$**，不涉及输入位宽。
> 而讲矩阵乘法量化的那两页里，$b$ 指的是**输入位宽 $b_X$**——它决定把输入拆成几位、
> 一个权重摊成几个常数。两者是同一个量在层边界两侧的名字：
>
> $$b_X\ (\text{下一层})=b_Y\ (\text{本层})$$
>
> **位宽本身不是本页的产物。** 每一层的位宽都在量化网络的设计阶段一并给定
> （或在设计过程中逐步确定），本页把它当已知条件，用它写出 $\Gamma_j$、$\Omega$ 与 $\delta_{Y,j}$。

## 一、继承什么

两条矩阵乘法链给出的东西形态一模一样：

| | 数模结合 | 强模 LUT |
|---|---|---|
| $N_j$ | $\sum_{k,i}W^{(k)}_{j,i}X_i^{(k)}-C_{j,\min}$ | $\sum_{l,i}\Lambda^{(l)}_{j,i}\bigl(\Xi_i^{(l)}\bigr)$ |
| $N_j^{\max}$ | $\sum\lvert W\rvert$ | $\sum\mathrm{round}(15\rho)$ |
| $\sigma_j$ | 缩放因子（编译时算出） | $1/\kappa$（斜率换算系数取倒数） |

**只有“$\sigma_j$ 怎么来”这一句不同，零点之后完全同构。** 本页余下内容对两者都成立。

---

## 二、零点 $P_j$

零点不需要任何“输入原点”之类的额外记号，它只有一个定义：

$$\boxed{\ P_j=\mathrm{round}\Bigl(C_j\big|_{\eta_j=0}-C_{j,\min}\Bigr)\ }$$

即“**实数预激活正好为 0 处的那个整数量**”。它一口吃掉两样都是常数的东西：
实数偏置与输入原点的贡献、以及矩阵乘法留下的偏移。

$$\boxed{\ \text{减零点这一步同时完成“去偏置”和“去常数”}\ }$$

$P_j$ 可以落在 $[0,N_j^{\max}]$ 之外——它只是被减掉的一个常数。
**它是两种输出的公共起点**：有 RELU 的层它同时是阈值，没有 RELU 的层它只是零点。

---

## 三、开关 C：压成 RELU 还是截成 CLIP

### 3.1 RELU：除以常数步长

$$\boxed{\ Y_j=\mathrm{RELU}(N_j)=\mathrm{clip}\left(\left\lfloor\frac{N_j-P_j}{\Gamma_j}\right\rfloor,\ 0,\ 2^{b_Y}-1\right)\ }$$

$$\Gamma_j=\left\lceil\frac{N_j^{\max}-P_j}{2^{b_Y}-1}\right\rceil$$

$\Gamma_j$ 是**整数**，含义是“每级吃掉多少个 $N$ 单位”。分母取 $2^{b_Y}-1$ 而不是 $2^{b_Y}$：
两者实测只差 0.01 个百分点，但取 $2^{b_Y}-1$ 能让 $Y_j\le2^{b_Y}-1$ **由构造保证**，不必靠 clip 兜底。

“截掉负半轴”就藏在 clip 的下界里：$N_j\le P_j$ 时 $\lfloor\cdot\rfloor\le0$，被夹成 0。
**负值从未被表示过**——不是算出来再丢掉，而是根本没进入表达。

### 3.2 CLIP：只做截取，不压缩

$$\boxed{\ Y_j=\mathrm{clip}\bigl(N_j-P_j,\ 0,\ \Omega\bigr),\qquad \Omega=\mathrm{round}(\omega\,\sigma_j)\ }$$

$\omega$ 是该层输出的**实数上界**（由应用定），$\Omega$ 是它对应的整数上界。
CLIP 等于“两个 RELU”：下界截一次、上界截一次，**中间一级一级全保留，一级都不压缩**。

$$\text{RELU 层}=\text{零点}+\text{常数除法};\qquad \text{CLIP 层}=\text{零点}+\text{截取}$$

$$\boxed{\ \text{区别只有一句：要不要压缩}\ }$$

**上界必须写 $\Omega=\omega\sigma_j$，不能写成 $\omega$ 本身。** 写成 $\omega$ 等于把输出退化成
只有 $\omega+1$ 个取值，绝大多数像素会挤进饱和区，后面的档位再也分不开。

---

## 四、交给下一层什么

$$\text{RELU 层：}\quad \delta_{Y,j}=\frac{\Gamma_j}{\sigma_j}\qquad
\text{CLIP 层：}\quad \delta_{Y,j}=\frac{1}{\sigma_j}$$

| 量 | RELU 层 | CLIP 层 |
|---|---|---|
| 整数输出 | $0\sim2^{b_Y}-1$ | $0\sim\Omega$ |
| 下一层的分辨率 | $\Gamma_j/\sigma_j$（每级跨 $\Gamma_j$ 个单位） | $1/\sigma_j$（每级就是一个单位） |
| 下游位宽 | $b_Y$ | $\lceil\log_2(\Omega+1)\rceil$ |

**层间默认走 RELU。** 它把输出压到 $2^{b_Y}$ 档，正好是下一层入口的宽度；
CLIP 不压缩，输出档数多，一般只用在需要保留完整量程的出口（比如末层）。

### 下游位宽更窄时：重走一遍，不是截断

CLIP 的输出**没有经过除法**，它的量程由 $\omega$ 定：

$$\Omega=\omega\,\sigma_j$$

而 $\omega$ 是**按激活函数的需要**选的，不是按下游位宽选的。所以当下游只要更少的档位时，
把上界改小是错的——那只是把超出部分饱和掉，不是重新量化，量程内仍然是原来那么多档。

正确做法是**让这个量重走一遍 RELU 走过的路**：重新取一个零点 $P'$、一个步长 $\Gamma'$，

$$\boxed{\ Y'=\mathrm{clip}\left(\left\lfloor\frac{Y-P'}{\Gamma'}\right\rfloor,\ 0,\ 2^{b'}-1\right)\ }$$

形式上与 §3.1 完全一样，只是这回的“非负整数量”是 $Y$ 而不是 $N$。

$$\boxed{\ \text{CLIP 之后要换位宽，就得重新过一次“减零点、除步长”}\ }$$

> 换句话说：位宽不是事后能削的东西。$\Omega$ 与 $b'$ 对不上，说明这一步的量化没做完，
> 而不是“多出来的位可以直接丢掉”。

**CLIP 之后往往还有别的后处理**（归一化、查表映射等），那些不属于层间传递，本页讲到层输出为止。

## 五、误差账

| 取整 | 误差上界（实数） |
|---|---|
| 零点 $P_j$ | $1/(2\sigma_j)$ |
| RELU 除法（floor） | $\Gamma_j/\sigma_j$（**一整级**） |
| CLIP 截取 | 0（只有饱和，没有量化误差） |

RELU 用 floor 而不是 round，**误差是一整级**，比半数大一倍——这是为了换“$Y_j\le2^b-1$ 由构造保证”。
CLIP 层没有这个代价，但它在饱和区会丢信息，饱和比例取决于 $\omega$ 取得多宽。

---

## 六、算例

设某通道：$\sigma=1000$，$N\in[0,\ 30000]$，$P=3000$，$b_Y=8$。

$$\Gamma=\left\lceil\frac{30000-3000}{255}\right\rceil=\left\lceil105.9\right\rceil=106$$

$$Y=\mathrm{RELU}(N)=\mathrm{clip}\left(\left\lfloor\frac{N-3000}{106}\right\rfloor,\ 0,\ 255\right)$$

| $N$ | $Y$ | 说明 |
|---:|---:|---|
| 3000 | 0 | 恰在零点 |
| 5000 | 18 | |
| 30000 | 254 | 上界（不溢出，$\Gamma$ 上取整保证） |

$$\delta_{Y}=\frac{106}{1000}=0.106$$

若这一层改用 CLIP，取 $\omega=15$：$\Omega=\mathrm{round}(15\times1000)=15000$，输出 $0\sim15000$，
$\delta_{Y}=0.001$——档数变成一万多，量程完整保留，但要下一层吃得下。

## 判据与反例

1. **RELU 层是常数除法。** 除以 $\Gamma_j$，分母取 $2^{b_Y}-1$。
2. **CLIP 层不压缩。** 只夹 $[0,\Omega]$，中间一级一级保留；给它配除法是错的。
3. **CLIP 的上界是 $\Omega=\omega\sigma_j$，不是 $\omega$。** 写成实数上界本身会把输出压进饱和区。
4. **$\Gamma_j$ 要上取整。** 下取整会让 $Y_j$ 溢出 $2^{b_Y}-1$，那个通道永远是满的。
5. **RELU 的误差是一整级。** floor 的代价，不是半级。
6. **$P_j$ 里已经含 $-C_{j,\min}$。** 别再减一遍常数。
7. **位宽是给定量，不是本页的产物。** 全网络的各位宽在设计阶段一并给定（或逐步确定）；本页只用它写出 $\Gamma_j$、$\Omega$ 与 $\delta_{Y,j}$。层边界上它换个名字：本层的 $b_Y$ 就是下一层的 $b_X$。
8. **CLIP 的输出不能靠缩上界来对接更窄的下游。** $\Omega=\omega\sigma_j$ 由激活的需要定；位宽对不上时，必须重走一遍“减零点、除步长”，而不是把多出来的量程饱和掉。
9. **层间默认 RELU。** CLIP 是特例，它的下游通常不是下一层网络而是后处理。
