## 与我们现有结论的关系

### 被它证实的

- **隔方块读容器的 ≥15 门槛**：我们 `容器信号` 与 `投掷器` 都按“≥15 打断穿透”写，与 `hjkv/02 §7` 的源码一致。**C-01 的这一半结案。**
- **897 = 1 + 14×64**：`hjkv/03 §4` 独立枚举得 898/898、864（缺口 804）、790（缺口 730），与我们的表逐格吻合。

### 被它修正的

- **“多充能取最大”不成立**。真实规则是**扫描顺序 + 累加到 ≥15 就返回**。
  这解释了作者 R-01/R-02 说的“比较器优先级并不低”：不是优先级问题，是**顺序 + 提前返回**。
  hjkv 的证据是 6730 个烧录值：按 max 算有 **1173 个不符**，按扫描算 **6730 个全对**。

### 与它冲突、需要实测的

- **`hjkv/03 §6`：MC 26.1.2 上，27 格各 64 把剑只读到 15，1 格 64 把剑读到 0**，与 1.20/1.21 源码公式对不上，怀疑 26.x 改了满度算法。
  这直接触及我们 `容器信号` 的“897 可达”结论。**已登记为 C-23，等作者裁定**（是版本差异，还是他的实验方法问题）。
