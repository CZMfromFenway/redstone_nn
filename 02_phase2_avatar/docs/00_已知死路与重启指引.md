## 0. 为什么二期值得做

一期证明了：**强模网络能做分类**。

但分类有个隐含的便宜可占 —— **网络是"收缩"的**：

```
225 个输入像素  →  10 个输出分数  →  取最大
```

红石只需要**一次聚合 + 一个 argmax** 就够了。

**生成不是收缩**：

```
64 个输入  →  64 个输出像素，每个都要有自己的值
```

**每个输出像素都需要一条独立的聚合通路。**

$$\text{分类} = 1\ \text{次聚合}\qquad\text{生成} = 64\ \text{次并行聚合}$$

**难点在结构上，不在堆电路上。** 这是"下一个红石突破"的所在。

## 1. 已知死路（**先读这一节，别重复**）

一期在头像生成上做过九种方案，**全部失败**。以下是每一条的原因，**这些是硬结论**。

> **⚠️ 勘误（2026-10-16 二期实测后补）**：下表的 1.1、1.2、1.3 三条已被撤销或降级，
> 详见 [`../PHASE2_TIMELINE.md`](../PHASE2_TIMELINE.md) 附录 A.1。其余各条仍成立。
> 保留下来的可迁移教训是：**"死路"多半是"那一次实验的配置有问题"，不是"这条路不通"** ——
> 所以在把任何一条当成禁令之前，先查它的证据链。

### 1.1 无条件 GAN —— 判别器不学

| 项 | 内容 |
|---|---|
| 做法 | 标准 DCGAN 结构，生成器输入噪声 |
| 现象 | 判别器不收敛，生成器永远停在噪声 |
| **排查** | 做了**梯度检验**，证明实现无误（梯度数值与解析一致） |
| **结论** | 不是代码 bug，是**这个规模/结构下 GAN 训练不动** |

> **别重复**：除非你有办法让判别器在 8×8 这种极小分辨率上学到东西。

### 1.2 朴素贝叶斯混合 —— 条件独立破坏空间结构

| 项 | 内容 |
|---|---|
| 做法 | 把每个像素当独立变量，建模 $P(\text{pixel}\mid\text{class})$ |
| 现象 | 生成结果像随机噪点 |
| **结论** | **条件独立假设破坏了空间相关性** —— 这是数学上的必然，不是调参问题 |

> **别重复**：任何"逐像素独立"的生成模型都会退化。

### 1.3 条件 GAN —— 把调色板索引当标量

| 项 | 内容 |
|---|---|
| 做法 | 以类别/属性为条件训练 GAN |
| 现象 | 颜色完全错乱 |
| **结论** | 把**离散调色板索引当连续标量**处理 → 颜色空间的拓扑被破坏 |

> **教训**：颜色是**离散类别**，不是连续数。任何对它做加减平均的操作都是错的。

### 1.4 自回归 —— 训练/生成不匹配 + 模式崩塌

| 项 | 内容 |
|---|---|
| 做法 | 逐像素生成，每步以已生成像素为条件 |
| 现象 | 生成结果单一（模式崩塌），且与训练分布不符 |
| **结论** | 训练时的**教师强制**与生成时的**自采样**分布不匹配（exposure bias） |

> **别重复**：除非解决 exposure bias（如 scheduled sampling），否则必崩。

### 1.5 蒸馏 —— 逐位置独立 → 马赛克

| 项 | 内容 |
|---|---|
| 做法 | 用一个大模型/教师生成样本，蒸馏到小模型 |
| 现象 | 输出像马赛克 |
| **结论** | 蒸馏目标**逐位置独立**，且**教师本身有噪声** → 学到的是噪声的平均 |

### 1.6 卷积 + MSE —— 学条件均值 → 退化成 2 色

| 项 | 内容 |
|---|---|
| 做法 | 卷积网络，MSE 损失 |
| 现象 | 输出退化成 2 色（背景 + 一种前景色） |
| **结论** | **MSE 的最优解是条件均值**。像素颜色的条件分布是多峰的，均值落在"大家都不像"的地方 |

$$\text{MSE}\ \Longrightarrow\ \hat{y}=\mathbb{E}[y\mid x]\ \Longrightarrow\ \text{模糊的平均脸}$$

> **这是最重要的一条**：**用 MSE 做生成，数学上必然退化。**

### 1.7 卷积 v2 —— "未知"与"白色"编码冲突

| 项 | 内容 |
|---|---|
| 做法 | 改进版卷积，加了"未知"状态 |
| 现象 | **中轴线白色占 25.81%** |
| **修复** | 加独立的"未知标志通道" → 降到 **9.77%** |
| **代价** | 准确率从 0.567 → 0.677（修好了但不够） |
| **结论** | 编码设计错误会让模型**系统性地**在一个位置产生伪影 |

> **教训**：**输入/输出的编码方式本身是设计问题**，不是训练问题。一处编码冲突会产生可定位的系统性伪影。

### 1.8 唯一有输出的方案

| 项 | 内容 |
|---|---|
| 做法 | **混合近邻 + 对称约束** |
| 结果 | **能出可辨认头像**（最优：`sym_sym_30_0.png`，完全对称 + T=30） |
| **致命问题** | **不可移植红石** —— 它依赖"近邻查找"这种非神经网络操作 |

> **这条最有价值**：它说明**"能生成"和"能在红石里生成"是两件事**。

### 1.9 汇总表

| # | 路线 | 失败原因（一句话） |
|---:|---|---|
| 1 | 无条件 GAN | 判别器不学（非实现问题） |
| 2 | 朴素贝叶斯混合 | 条件独立破坏空间结构 |
| 3 | 条件 GAN | 离散调色板当连续标量 |
| 4 | 自回归 | 训练/生成分布不匹配 → 模式崩塌 |
| 5 | 蒸馏 | 逐位置独立 + 教师有噪声 |
| 6 | 卷积 + MSE | **MSE 最优解是条件均值 → 退化** |
| 7 | 卷积 v2 | 编码冲突（未知 vs 白色） |
| 8 | 混合近邻 + 对称 | 能出图，但**不可移植红石** |

## 2. 从死路里提炼的三条硬约束

### 约束 A：不能用 MSE / L1 这类重建损失

$$\text{重建损失}\ \Longrightarrow\ \text{条件均值}\ \Longrightarrow\ \text{模糊}$$

**必须用**：对抗损失、离散似然、或**离散化输出 + 分类损失**。

### 约束 B：不能逐像素独立

**必须显式建模空间相关性**（卷积、或全局注意力、或至少是整幅图作为一个样本）。

### 约束 C：颜色必须当离散类别

**不能对颜色做加减平均。**

## 3. 二期建议的起点

### 3.1 先做可行性判断，别急着写模型

**关键问题**：在红石里，生成 64 个输出像素，**每个像素要多少电路？**

一期的经验值：**225 个输入 → 10 个输出，用了 32×52×47**。

那么：

$$\text{64 输入} \to \text{64 输出}$$

如果每个输出像素要一条独立聚合通路，**电路规模约等于一期的 6.4 倍**（64 vs 10）。

**体积可能到 10⁶ 量级** —— **仍在"能做"的范围内，但要重新做布局设计。**

> **二期第一步应该是"电路规模估算"，不是"训练模型"。**
> 先证明"电路做得出来"，再训练。

### 3.2 建议的模型方向

| 方向 | 理由 |
|---|---|
| **离散输出 + 分类损失** | 避开约束 A（MSE 陷阱） |
| **小卷积 / 局部感受野** | 避开约束 B（空间相关） |
| **极低分辨率（8×8 或 16×16）** | 先证明结构可行，不追求画质 |
| **对称性作为硬约束** | 一期唯一成功的方案用了这个，值得保留 |

### 3.3 明确的"不要做"

| 不要做 | 原因 |
|---|---|
| 再试 GAN | 死路 1，判别器在此规模不学 |
| 用 MSE / L1 | 死路 6，数学上必然模糊 |
| 逐像素独立建模 | 死路 2、5 |
| 把颜色当连续值 | 死路 3 |
| 上一层的大卷积网络 | 红石装不下 |
