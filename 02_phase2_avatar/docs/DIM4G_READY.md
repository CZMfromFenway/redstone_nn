| 臂 | 输出变换 | 对比度 | 发灰率 | 红石成本 |
|---|---|---:|---:|---|
| `dim4x` | min-max 拉伸 | 15.00 | 0.00% | 极值比较 + 除法 |
| **`dim4g`** | **全局增益 ×1.7** | **11.36** | 8.73% | **一次乘法 + 一次加法** |
| `dim22` | 无 | 12.07 | 0.53% | 参照锚点 |

**为什么用全局增益而不是逐通道增益** ——这个我实测过，反直觉：

我先做了**逐通道仿射**（每通道各自的 gain 和 offset，匹配真实脸在该位置的均值/方差）：

| 变换 | 对比度 | 发灰率 |
|---|---:|---:|
| 真实脸 | 11.20 | 9.7% |
| 原始 | 8.71 | 14.8% |
| min-max | 15.00 | 0.0% |
| **全局增益 ×1.7** | **11.25** | 7.1% |
| **逐通道仿射** | **9.85** | 10.1% |

**逐通道标定反而更差。**

原因：逐通道匹配的是**每个位置跨样本的时间方差**，而一张脸的对比度取决于**同一张脸内部位置之间的差异**。
全局增益放大位置间差异；逐通道标定不放大它，甚至把它压平。

**所以红石里"所有 $B_i$ 相等"不是妥协，而是更优解——而且更简单。**

## 三、关于你的 min-max 方案

你描述的"转数电取最大值 → 去掉低 4 位 → 转回模电作为 B"，我理解是：

$$B = \left\lfloor \frac{\max}{16} \right\rfloor,\qquad \text{level} = \left\lfloor \frac{v}{B} \right\rfloor = \left\lfloor \frac{16v}{\max} \right\rfloor$$

**右移 4 位确实是免费的**，而且 $\lfloor 16v/\max \rfloor$ 正好就是拉伸后的 0~16 级。
关键成本只剩"**除以一个变量 B**"这一步。

**实测的取舍**：

| | min-max | 全局增益 |
|---|---|---|
| 对比度 | 15.00（超过真实 11.20） | **11.25（几乎等于真实）** |
| 发灰率 | 0.00%（真实有 9.7%） | **7.1%（接近真实）** |
| 良率（已测） | **~58%** | 待测 |
| 红石 | 极值 + 带变量除法 | **一次乘法** |

**min-max 会让对比度超过真实分布**——它保证每张脸都铺满，但真实脸并不都铺满。

第 4 轮要回答的就是：**这个"过度拉伸"是否反而更讨你喜欢。**
