# 训练记录

**这里放的是“过程”，不是“结论”。**

和知识库其他目录比，这一层的地位**刻意低一档**：

| | 知识库正文（`10`/`20`/`30`…） | 本目录 |
|---|---|---|
| 回答什么 | 现在什么是真的 | 当时是怎么试出来的、走过哪些弯路 |
| 能不能被引用 | 能（`定案` 页优先于一切） | **原则上不引**；只在追溯“这条结论当初怎么来的”时看 |
| 状态 | 定案 / 待验 | `记录` |

一句话：**结论上升进 `20_数学`、`30_理论` 那些页；过程留在本目录。**

## 收录原则

1. **只收“最后敲定的”与“明确被证伪的”**，中间过程不收。
2. 每条都要能回答“**这条是测出来的还是猜的**”。
3. 与知识库正文冲突时，**以正文为准**，在这里记下冲突即可，不要反过来改正文。
4. 图表放 `kb/figures/`，不要在本目录里散放图片。
