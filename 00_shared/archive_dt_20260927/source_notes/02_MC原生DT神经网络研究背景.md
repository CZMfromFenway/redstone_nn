# 新对话附加研究背景：Minecraft 原生 D/T 神经网络

> **与《D_T结构数学研究总结_修正版_v1.md》配套使用。**  
> 前一份文档负责 D/T 的数学定义与已完成穷举；本文只补充 Minecraft 神经网络的工程背景、研究假设、仿真任务和可行性判据。  
> 目标不是把现有 CNN/MLP 原样搬进 Minecraft，而是判断：**能否利用 Minecraft 比较器、0～15 模电信号、廉价 `max` 聚合以及 D/T 强非线性，提出一种更符合红石物理成本结构的网络构型。**

---

# 1. 已存在的 Minecraft 神经网络基线

Minecraft 中已经有人完成了较大规模、可工作的纯红石神经网络，不能把“红石神经网络”本身当成新颖点。

重点参考对象：

- B站用户：**辰占鳌头**
- 项目：纯红石手写数字识别神经网络
- 主视频：`BV1yv4y1u7ZX`
- 原理视频：同系列《Minecraft 红石卷积神经网络——原理》
- 教程系列还包括随机数、随机强度、模电计数、卷积核和向量内积。

公开资料确认：
- 该项目能进行手写数字识别；
- 作者简介中报告在 MNIST 模拟上约 **80%** 准确率；
- 使用了压缩后的卷积神经网络思路；
- 卷积核大小为 **3×3**；
- 公开报道给出的整体层级为：

\[
15\times15 \to 7\times7 \to 30 \to 30 \to 10
\]

- 后半部分是 `30→30→10` 的全连接网络；
- 现有资料不能仅凭上述层数断言中间的 `15×15→7×7` 是否包含独立池化层，因此**池化是否存在暂时记为未知，后续应直接核对原理视频/存档/代码**。

已知实现思路还包括：
- 在 Minecraft 内实现卷积；
- 使用随机串或相关随机计算技术处理乘法/权重；
- 全连接神经元需要进行加权聚合；
- 网络权重在游戏外训练/生成，再部署到 Minecraft；
- 不是在 Minecraft 内做完整反向传播训练。

因此新的研究应该把该项目视为**传统神经网络映射到红石硬件的强基线**。

# 2. Minecraft 中的计算成本与普通神经网络非常不对称

以下不是已经证明的数学定律，而是当前红石工程经验形成的**研究先验 / 成本假设**。新对话需要进一步量化，不应直接当作定论。

## 2.1 矩阵乘法很贵

传统神经元的核心通常是：

\[
y=\phi\left(\sum_i w_i x_i+b\right)
\]

在 Minecraft 中，真正昂贵的部分往往不是激活函数，而是：

- 一个输出要扇出到大量下游神经元；
- 每条连接需要携带权重；
- 需要乘法；
- 需要多输入求和；
- 需要长距离布线；
- 需要同步、延迟管理和信号保存。

因此“参数量少”并不自动等于“红石成本低”。

红石成本模型必须显式加入：

\[
\text{fanout}+\text{wire length}+\text{multiply}+\text{sum}+\text{latency}
\]

而不是只数神经元。

---

# 3. 比较器天然带有非线性

红石比较器信号被限制在：

\[
0,1,\dots,15
\]

并且比较/减法模式天然包含：

- 截断；
- 阈值；
- 饱和；
- 差值；
- 最大值相关行为。

因此在 Minecraft 中，“激活函数”本身通常远比现实计算机中的矩阵乘法便宜。

可以把比较器看成天然带有限域非线性的算术元件，而不是把它当成需要额外实现 ReLU 的普通加法器。

D/T 结构进一步把这种性质放大：

> **我们面对的是“激活函数很强，但全连接能力很弱”的硬件环境。**

---

# 4. `max` 比求和便宜

多个信号汇合时，Minecraft 红石天然很容易实现：

\[
\max(x_1,x_2,\dots,x_n)
\]

而传统神经网络更常需要：

\[
\sum_i x_i.
\]

当前工程判断是：

\[
\operatorname{cost}(\max)
\ll
\operatorname{cost}(\sum).
\]

因此新的网络不应默认“加权和”必须是神经元的基本聚合算子。

一个核心研究方向是：

\[
\boxed{
\text{能否用 max / compare / subtract / threshold
取代大量 multiply + sum？}
}
\]

---

# 5. 权重乘法的成本随信号表示急剧上升

当前提出一个**待量化的成本等级假说**。

若一个神经元的输出参与权重乘法：

### 情况 A：输出只有 0/1

\[
x\in\{0,1\}
\]

则：

\[
w x
\]

本质上接近“是否放行权重”，成本最低。

### 情况 B：多值离散整数

若输出允许：

\[
x\in\{0,\dots,n\},
\]

则需要更复杂的乘法或重复组合。

### 情况 C：更高精度整数

乘法成本进一步快速增加。

### 情况 D：浮点

在纯红石里基本不应视为正常工程方案。

czm 当前给出的粗略直觉比例是：

\[
\boxed{
1:n:n^3:\infty
}
\]

它只表达**增长等级直觉**，不是经过测量的正式复杂度结论。

新研究需要把这个比例变成可测量指标，例如：

- 方块数；
- 比较器数；
- 红石粉数；
- 中继器数；
- 体积；
- tick 延迟；
- 扇出代价；
- 每次推理的随机计算周期。

---

# 6. 卷积和池化也不是免费的

传统 CNN 通过局部连接和权重共享降低参数量，但在 Minecraft 中：

- 局部窗口仍需布线；
- 卷积仍涉及多次乘法和累加；
- 特征图需要传输；
- 池化需要窗口聚合；
- 多通道会进一步增加布线和计算。

当前估计卷积/池化相关成本可能在：

\[
O(n)\sim O(n^2)
\]

的工程尺度上，但这里的 \(n\) 尚未严格定义。

因此新研究不能因为“CNN 在现实硬件上高效”就默认“CNN 在红石中也一定最优”。

---

# 7. 0～15 模电信号：存储紧凑，传输昂贵

比较器容器、红石信号强度等方式可以很紧凑地保存：

\[
0\sim15
\]

的整数。

这相当于一个 4-bit 多值信号。

优点：

- 存储密度高；
- D/T 可以直接利用数值强度；
- 一个信号可以携带比单比特更多的信息。

缺点：

- 长距离模拟强度传输不方便；
- 扇出到许多位置的成本高；
- 跨层大量复制模拟值会迅速放大布线成本。

因此一个关键矛盾是：

\[
\boxed{
\text{模电“局部计算”很强，
模电“全局广播”很弱。}
}
\]

这应成为新架构的核心约束。

---

# 8. D/T 在这个环境中的角色

目前 D/T 的数学研究显示：

- 单个 D/T 已经能表达大量分段非线性；
- 少量嵌套后函数族迅速增长；
- 顺序很重要；
- T 尤其擅长动态阈值；
- 中间 0～15 模拟输出可以被后续结构再次切分；
- 分叉/汇合拓扑与简单串行拓扑不是同一个函数族。

因此可以把 D/T 暂时理解成：

> **参数很少、非线性很强、适合处理一个局部模拟信号的“强激活单元”。**

当前有一个重要但尚未证明的猜想：

\[
\boxed{
\text{有限个 D/T 嵌套可能覆盖大量，
甚至最终覆盖全部 }16\to16\text{ 离散映射。}
}
\]

完整映射空间大小为：

\[
16^{16}.
\]

这个猜想必须用计算实验研究，不能提前当作事实。

---

# 9. 整个研究场景的一句话描述

\[
\boxed{
\text{强激活函数 + 弱全连接能力}
}
\]

传统神经网络的优势通常建立在：

> 大量便宜的乘加运算 + 相对简单的激活函数

Minecraft 红石的成本结构恰好可能接近反过来：

> 乘加和广播昂贵 + 比较、截断、max、0～15 局部模电运算以及 D/T 非线性相对便宜

因此真正值得研究的问题不是：

> “怎样把普通 MLP/CNN 做得更小？”

而是：

\[
\boxed{
\text{如果硬件原语的价格表完全不同，
网络本身应该长成什么样？}
}
\]

# 10. 新对话的核心研究任务

新对话只研究一个主题：

> **探索以 D/T 为核心运算单元，能否提出一种适合 Minecraft 红石成本模型的新型神经网络或学习网络构型。**

不要预设答案一定是“神经网络”。

如果最终更接近：

- 多值逻辑网络；
- max-plus 网络；
- morphological network；
- lattice network；
- decision network；
- 可训练查找网络；
- 离散函数网络；

也可以接受。

在声称“新构型”之前，需要主动检索并比较现实中已有的：

- Maxout；
- max-plus / tropical neural network；
- morphological neural network；
- lattice / min-max network；
- binary neural network；
- quantized neural network；
- threshold network；
- decision tree / decision list；
- LUT network / FPGA neural network。

目标是确认 D/T 架构到底是：

1. 已知模型的 Minecraft 物理实现；
2. 已知模型的特殊离散变体；
3. 还是确实存在新的结构性质。

# 11. 第一阶段：不要直接上 MNIST

首先做**函数能力仿真**。

## 11.1 单输入 D/T 网络

输入：

\[
x\in\{0,\dots,15\}
\]

研究：

- 深度 1、2、3、4……时能覆盖多少 \(16\to16\) 映射；
- 是否最终饱和；
- 多深可以覆盖全部 16 位二值真值表；
- 串行和分叉汇合谁增长更快；
- 哪种拓扑单位红石成本表达能力最高。

指标：

\[
\frac{\text{new functions}}{\text{estimated redstone cost}}
\]

---

## 11.2 多输入基础任务

再进入：

\[
(x_1,x_2)\to y
\]

先不要做图像。

建议依次测试：

- AND / OR / XOR；
- 比大小；
- 奇偶；
- 区间分类；
- 两数关系；
- 小型随机真值表；
- 2D 几何分类；
- 非线性可分任务。

目的不是展示 AI，而是判断：

> D/T 网络如何利用多个输入，而不重新跌回昂贵的矩阵乘法。

---

# 12. 第二阶段：探索“廉价聚合器”

需要至少比较以下网络节点。

## A. 传统加权和

\[
z=\sum_i w_i x_i
\]

作为高成本基线。

## B. max 聚合

\[
z=\max_i f_i(x_i)
\]

其中 \(f_i\) 可以由 D/T 实现。

## C. max + threshold

\[
y=T\left(\max_i f_i(x_i)\right)
\]

## D. 多支路 winner-take-all

每个输入经过局部 D/T 变换，仅让最强分支继续传播。

## E. 二值化后加权

先：

\[
b_i=\mathbf1[f_i(x_i)>k_i]
\]

再使用低成本 0/1 权重门控。

## F. 小局部模拟 + 长距离数电

只在局部保留 0～15：

\[
\text{analog local feature}
\]

到跨区域通信前转为：

\[
0/1
\quad\text{或少量等级}
\]

以降低 fanout。

这可能是非常适合 Minecraft 的折中方式。

---

# 13. 第三阶段：建立 Minecraft 成本模型

如果没有成本模型，就无法判断一个新网络是否真的更好。

建议为每种原语定义成本向量：

\[
C=
(B,V,L,T,F,M,A,R)
\]

例如：

- \(B\)：总方块数；
- \(V\)：体积；
- \(L\)：布线长度；
- \(T\)：tick 延迟；
- \(F\)：fanout / 信号复制成本；
- \(M\)：乘法成本；
- \(A\)：加法/累加成本；
- \(R\)：随机计算所需周期或随机元件成本。

最终不要急着压成一个数字，先做 Pareto 比较。

---

# 14. 第四阶段：训练 / 搜索方式

Minecraft 内不必承担训练。

合理路线是：

\[
\boxed{
\text{Python 仿真训练/搜索}
\to
\text{离散化}
\to
\text{编译成 D/T 参数}
\to
\text{Minecraft 部署}
}
\]

应同时比较几种优化方式：

### 1. 穷举

适合小结构、小参数空间。

### 2. 动态规划 / SAT / SMT

用于精确寻找最小网络。

### 3. 遗传算法

同时搜索拓扑和参数。

### 4. 离散局部搜索

每次修改一个 D/T 参数或一条连接。

### 5. 进化式神经架构搜索

目标函数直接包含：

\[
\text{classification loss}
+
\lambda\cdot\text{redstone cost}.
\]

这一步很关键：

> 不要先设计一个普通网络，再想办法压缩成红石。  
> 应让“红石成本”从训练/搜索开始就进入目标函数。

---

# 15. 第五阶段：再进入手写数字识别

当多输入架构有稳定结果后，再与辰占鳌头的方案做对照。

至少建立三个软件基线：

## Baseline A：普通小型 MLP

验证完全连接的准确率和运算量。

## Baseline B：辰占鳌头式压缩 CNN

尽可能复现：

\[
15\times15\to7\times7\to30\to30\to10.
\]

## Baseline C：D/T 原生网络

使用相同输入数据。

比较：

- 准确率；
- 节点数；
- 连接数；
- 乘法次数；
- 求和次数；
- max 次数；
- 模拟信号长距离传输次数；
- fanout；
- 估计方块数；
- 估计体积；
- tick 延迟。

最终判断的是：

\[
\boxed{
\text{相同准确率下，Minecraft 实现成本是否显著下降。}
}
\]

而不是仅比较 Python FLOPs。

# 16. 一个非常值得优先测试的架构假说

当前最有价值的假说之一是：

\[
\boxed{
y_j
=
G_j\left(
\max_i F_{ij}(x_i)
\right)
}
\]

其中：

- \(F_{ij}\) 不是普通乘权，而是小型 D/T 函数；
- 聚合器使用廉价 `max`；
- \(G_j\) 也是 D/T 或简单阈值；
- 长距离输出尽量二值化。

这和普通神经元：

\[
\phi\left(\sum_iw_{ij}x_i\right)
\]

的成本结构完全不同。

它应该作为第一类候选，而不是结论。

需要测试它：

- 分类能力；
- 是否能训练；
- 表达能力；
- 是否需要过多节点弥补缺少求和；
- 是否实际降低红石面积和延迟。

---

# 17. 第二个候选：局部强非线性 + 稀疏路由

另一个候选方向：

1. 输入只连接到很少的局部节点；
2. 每个节点内部用 D/T 做复杂映射；
3. 节点输出尽早压成 0/1；
4. 后续使用稀疏连接；
5. 避免一个多值模拟输出广播到几十个神经元。

即：

\[
\boxed{
\text{用“节点内部复杂度”
换“节点之间连接复杂度”。}
}
\]

这与 Minecraft 的物理成本非常匹配，也是需要重点验证的核心假说。

---

# 18. 可行性判据

研究不能只问“能不能算”。

建议设四个 Gate。

## Gate 1：函数能力

D/T 网络是否能完成基础非线性分类任务？

## Gate 2：可训练性

是否能通过自动搜索稳定找到参数，而不是只能手工碰巧构造？

## Gate 3：成本优势

相同任务、相近准确率下，是否明显减少：

- 加权乘法；
- 求和；
- fanout；
- 长距离模拟传输。

## Gate 4：Minecraft 可建造性

能否给出规则化、可堆叠、可布线的实际红石单元？

只有四个 Gate 都通过，才值得把它称为一个真正具有工程意义的 Minecraft 原生学习网络。

>
> \[
> y_j=G_j(\max_iF_{ij}(x_i))
> \]
>
> 以及“局部保留 0～15 强非线性、跨区域尽早二值化、稀疏连接”的网络。
>
> 最终目标不是为了证明 D/T 一定能成为神经网络，而是找出：**是否存在一种在 Minecraft 红石里比传统乘加神经网络更自然、更紧凑、更快、更可堆叠的学习型网络构型。**
