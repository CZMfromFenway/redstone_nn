# w128 打标结果：提升 47 个百分点

> 111 个人工标签（差 21 / 中 45 / 良 40 / 优 5），模型 `22→128→128→32`（23,296 次乘法）

---

## 一、结论：提升很大，远超上次

| 保留比例 | 真实"优+良"命中率 | 相对不筛选 |
|---|---:|---:|
| **100%（不筛选）** | **40.7%** | — |
| 50% | 61.2% | +20.6 |
| 35% | 73.2% | +32.6 |
| 25% | 78.8% | +38.2 |
| **15%** | **87.5%** | **+47.0** |

**2.15 倍。** 而且**越往下筛越好**——上次 lam5 在 15% 时开始反转（72.5%），这次一直升到 87.5%，
说明排序在顶端仍有真信号。

**留出集交叉验证 AUC = 0.795**（上次 lam5 只有 0.617）。

---

## 二、为什么这次好得多

| | lam5（512 输出） | **w128（32 输出）** |
|---|---:|---:|
| 标签数 | 159 | 111 |
| 留出集 AUC | 0.617 | **0.795** |
| 类别分离度 | 0.318 | **0.746** |
| 优+良 基线率 | 67.3% | 40.5% |
| 最佳筛选收益 | +7.2 点 | **+47.0 点** |

**两个原因：**

1. **缺陷更一致。** w128 的主要问题是"糊"（只有 26% 的输出落在整数级上），
   这是一个**视觉上显著且稳定**的性质，比 lam5 那些细微差别更容易学。
2. **类别更均衡。** 你给 w128 打了 18.9% 的"差"，lam5 只有 6.3%。
   **判断"明显不行"比判断"细微的好"更可靠。**

## 三、模型学到的：你偏好什么

奖励模型最强的几个轴（线性，22 个参数）：

| 主成分 | 权重 | 方向 |
|---|---:|---|
| **PC2** | **−0.300** | 增大 → 你不喜欢 |
| **PC1** | **−0.259** | 增大 → 你不喜欢 |
| PC7 | **+0.158** | 增大 → 你喜欢 |
| PC11 | +0.142 | 增大 → 你喜欢 |
| PC4 | +0.116 | 增大 → 你喜欢 |

**PC1 和 PC2 都是负权重**（和上次 lam5 一致）——你偏好**靠近原点、不那么"夸张"的脸**。
但这次多了几个正向轴（PC7、PC11、PC4），说明**在这个更小的模型里，你也偏好某些特定方向的变化**，
而不是一味求平均。

## 四、实际采样效果

同一套参数下：

| 采样方式 | 平均预测分 | 相邻同色率 |
|---|---:|---:|
| 随机 N(0,1) | 0.858 | 57.8% |
| **筛选（前 15%）** | **1.682** | **61.2%** |

**筛选后的样本不只是"更符合偏好"，还更平滑**（57.8%→61.2%）。
这说明你偏好的方向恰好也抑制了模糊——**打分和视觉质量是一致的，不是矛盾的。**

## 六、必须指出的局限

**这次对比仍然是非盲的。** 你知道右边是筛选过的，可能不自觉地偏向它。

虽然 AUC 0.795 是**盲的**（交叉验证时模型没见过那些标签），
但"你觉得筛出来更好看"这个判断本身还没经过盲测。

**建议的盲测**：把随机样本和筛选样本混在一起打乱，不告来源，再打 30 张。
如果盲测里筛选组仍然显著更高，那结论就完全确立了。

## 七、还能继续提升吗

**能。** 证据：收益在保留 15% 时还没见顶（还在升）。

| 做法 | 预期 |
|---|---|
| 再加 50~100 个标签 | AUC 继续上升，筛选收益可能突破 50 点 |
| 换非线性模型 | **不建议**——上次 lam5 上 MLP 输给线性 2.5 点（过拟合） |
| 打标时放慢速度 | 2.9 秒/张仍偏快，放慢可能降低判断噪声 |

**注意**：继续打标要用**同一个模型（w128）**，标签不能跨架构混用。
