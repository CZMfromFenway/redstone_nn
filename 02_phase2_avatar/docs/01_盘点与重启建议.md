### 2.2 两次独立审计的结论：旧结论比"没走通"还要弱

本次会话派了两份独立审计（一读 GAN 代码+日志，一重跑数据管线）。
两份都指向同一件事：**旧研究那批"硬结论"，前提条件本身就站不住。**

#### (a) GAN 那次实验**根本没有 50k 数据**（决定性）

| 证据 | 内容 |
|---|---|
| 数据集成型时间 | `faces8.npy` / `faces8_rgb.npy` 写于 **2026-10-05 11:48:57** |
| GAN 产物时间 | **2026-10-04 21:33 / 22:01 / 22:22 / 22:32** —— **早 13 小时** |
| 脚本自述 | `gan_train2.py:9` 写着「样本仅 **1205**」 |
| 皮肤下载曲线 | 20:00 有 686 张 → 21:33 有 1605 张 → 21:53 才 5820 张 |
| 交叉验证 | 用现在的 50k 数据**无法复现** `gan_real.png`（任意 n 都不行）；两个 real 网格共享 **0/48** 格，尽管都用了 `default_rng(123)` |

**所以归档里的无条件 GAN 是在约 1.2k~5.5k 张图上训练的，从没在 50k 上跑过。**
「8×8 这个规模 GAN 学不动」这句话的数据基础，是**一千多张图**。

#### (b) 判据本身是个坏尺子

旧脚本汇报的是「256 张真 / 256 张假上的 **sigmoid 均值**」。而它用了
**标签平滑到 0.9**：常数预测器的最优解恰好是

$$p^\*=0.45\quad\left(\text{解 }(p-0.9)+(p-0)=0\right)$$

**0.45 就是标签平滑的常数最优值**，不是"判别器什么都没学到"的证据，
也不是"纳什均衡"的证据（后者要求生成器已经匹配数据，而它没有）。
**这个数字无法区分理论上完全不同的两种失败。**

#### (c) 决定性反证：判别器**学得会**

审计用**同一份 D、同一个 lr=1e-4**，只把它单独拿去训练：

| 设置 | 判别准确率 |
|---|---|
| 单独训练 D（同一生成器、同一 lr） | **95.5% ~ 98.4%**（每个 checkpoint 都是） |
| 对归档保存的 G 权重 | **99.0% / 97.9%** |
| **单层线性分类器** | **98.4% / 97.6%** |
| 而联合训练里的 D | **50.8%** |

**信息完全存在，而且一层线性就能取出来。联合更新把它丢掉了。**

#### (d) 架构描述是错的

旧文档称其为「**标准 DCGAN 结构**」。实际是：
`z(32) → Linear(32,128) → ReLU → Linear(128,64) → tanh`，
判别器 `64 → 64 → 1`。**没有卷积，没有 BatchNorm** —— 是个 2 层 MLP。

#### (e) 数据侧也有污染（第二份审计）

| 缺陷 | 实测数据 |
|---|---|
| **alpha 被直接丢弃** | 全库 **52,690 条（4.76%）** 头部正面**完全透明** → 被当成**全黑头像**；50k 里存活 40 条全透明（39 条藏着不可见 RGB）。透明像素 93% 恰好是 (0,0,0)，把调色板 8 号 `(4,4,4)` 抬到**全部像素的 12.6%** |
| **脸部级重复** | 1,107,411 条里只有 **932,636 个不同裁切**（重复 15.78%）；**最大的一个"全黑裁切"出现 51,156 次**；扫描窗口内一个全黑裁切出现 2,766 次 |
| **不是随机样本** | 提取逻辑是「按 zip 顺序取满前 50,000 个不同裁切」，是**模板聚集数据的头 8.2%** |
| **原地覆盖毁掉溯源** | 两个 npy 被同一个脚本原地重写，**2026-10-04 那批结果（gan_* / capacity* / mixture / sym_*）所依据的数据集已不存在**，无法复现 |

#### (f) 顺带确认的"好"消息

zip 的 SHA-256 **等于 HuggingFace 的 LFS oid**，与上游**逐字节一致**；
1,107,411 张 PNG **全部解码成功、全部 64×64、0 损坏**；
裁切区 (8,8)-(16,16) **正确且块对齐**（平移 1 像素会让"完全不透明"从 94.6% 掉到 5.2%）；
无 RGB/BGR 交换、无转置错误、无越界索引；
调色板量化不变量**精确成立**（320 万像素 0 处不符）；
指标 5.3132 / 57.79 / 0.8598 全部复现。

### 2.3 一句话总结这两份审计

> 「无条件 GAN 是死路」这个结论，建立在
> **一次约 1.2k 张图的实验** + **一个无法区分失败模式的判据** + **一份中途被换掉的数据** 之上。
>
> 而用同一份代码、同一个学习率，**单独训练判别器就能到 96~99%**。

这正好印证了你提醒的那句话：**踩过的坑不一定是坑，有时只是一个粗心导致的误判。**
这里具体是**三个**粗心叠加：数据集当时还不存在、指标读错含义、文档把 MLP 写成 DCGAN。

### 2.4 审计给出的技术性线索（下一轮直接可用）

| 线索 | 证据 | 下一轮怎么做 |
|---|---|---|
| **损失从没看见离散化** | 生成器用 `tanh` 连续回归到**有序调色板索引**；实测输出索引熵 3.92~3.94 bits、每样本 **11.8~12.2** 种颜色（真实 3.77 bits / 5.33 种）——高熵模糊，四舍五入后接近随机色 | **每像素 16 路 softmax + 分类损失**，让优化器看见离散化 |
| **真假梯度相互抵消**（推测，未证实） | 生成器**逐像素边缘统计已接近真实**（样本次序 std 0.515 vs 0.572；全局 0.562 vs 0.584）→ D 的真假两项梯度近乎抵消，Adam 把残差归一化成无信息的游走 | 针对这一点：**R1 / WGAN-GP / 谱归一化 / hinge / LSGAN / instance noise**。**注意：单纯削弱 D 已被证明无效** |
| **诊断指标不可用** | D 的 logit std 从 init 的 0.306/0.242 掉到第 25 轮的 0.065/0.048；`b2 → logit(0.45)`；D 退化成常数预测器，而报告里看不出来 | 记录 **D 在留出集上的 accuracy / AUC**、每 checkpoint 的 D loss，**永不只看 sigmoid 均值** |
| **无法区分"D 崩了"和"G 追上了"** | 从没保存过 D 的权重，也从没做过生成器快照 | 每 N 轮**冻结一个 G 快照**，用它给当前 D 打分 |
| **稳健性未知** | 只有 1 次运行、无多种子、数据在实验中途被换 | **≥3 个种子 × (5k, 50k) 两个数据规模**，再谈结论 |

## 3. 复算：一个关键的、可直接测量的分岔

用 `src/restart_probe.py` 在**同一协议**下同时测「采样」与「取众数」。
生成 64 张、原型池 20000、k=30 近邻：

| 方案 | 颜色数 | 多样性 | 对称率 | 到最近真实 | 生成样本最近邻距离中位 | 重复数 |
|---|---:|---:|---:|---:|---:|---:|
| 真实留出样本（参考） | 5.19 | 57.78 | 0.867 | 15.3 | 34 | 0/64 |
| **混合近邻 T=30 采样**（旧「最佳」） | **5.44** | 56.49 | **1.00** | 13.2 | 30 | 0/64 |
| **混合近邻 T=1 采样** | **4.95** | **56.78** | **1.00** | **4.1** | 32 | **0/64** |
| 近邻**逐位置取众数**（确定性） | **3.47** | 55.91 | 0.948 | 5.1 | **20** | **2/64** |
| 近邻**逐对取众数 + 镜像**（确定性） | **3.38** | 55.83 | 1.00 | 5.2 | **19** | **2/64** |

视觉对照见 `results/restart_probe_mixture_sym_T1.png`（采样，可辨认的脸）
与 `results/restart_probe_mode_pairmirror.png`（取众数，**退化成大色块**）。

### 这个测量说明了什么

1. **旧文档说「混合近邻法不可移植红石」是对的**，但它没说清可移植性到底缺什么。
   本次测量指出了缺的东西：**采样的能力**。
2. 同一个近邻模型，**只把「按权重采样」换成「取权重最大的颜色」**，
   颜色数就从 4.95 掉到 3.38，并开始产生**完全重复**的样本 —— 图像退化。
3. 因此「确定性前馈网络生成头像」这条路的困难，**不是网络太小，而是**
   $$\text{确定性输出}\ \Longrightarrow\ \text{只能输出众数/均值}\ \Longrightarrow\ \text{退化}$$
   这正好从另一个角度复现了旧文档死路 6（MSE → 条件均值 → 模糊）的同一个机理。
4. **推论（对重启最重要，但属于假设）**：如果生成质量确实依赖「把分布采样出来」，
   那么可行的方案就需要**携带随机源**。
   红石**本身就有**随机源（投掷器随机槽位、发射器、实体随机），
   所以「输出层接一个随机选择树」很可能是缺失的那块拼图 ——
   而这条路**旧研究一次都没试过**（它把「随机采样」和「非神经网络操作」混为一谈了）。

> ⚠️ 诚实的边界，必须说清三件事：
> 1. 上表只证明「**取众数会退化**」，**没有**证明「确定性网络一定失败」。
>    一个训练良好的确定性网络完全可以输出**清晰的类原型**而不是模糊均值。
> 2. 「采样是必需的」目前是**假设**，不是结论。它有一个**可直接判定的实验**：
>    把旧 `conv_student3.py` 的解码器从「采样」换成「argmax」，
>    其余不动，比较两个指标。如果 argmax 版明显更差，假设就被支持。
> 3. 上面第 2 行还顺带说明：旧文档死路 6 的「反复应用均值算子 = 不断模糊」
>    在**前馈一次性预测**里并不成立（不迭代就没有反复应用）。
>    它成立的场景是**迭代式精修**（旧蒸馏就是这样，反复迭代 36→51 像素发散）。
>    所以死路 6 的正确适用条件是「**迭代** + 均值/MSE」，不是「MSE」本身。

## 4. 旧「九条死路」的重新分类

### 4.1 无条件 GAN（旧结论：规模/结构问题，非 bug）—— **已被审计推翻，见 2.2**

本节最初写的判断（"未决，值得重试"）**方向对了但太保守**。审计后的事实是：

- **数据基础错了**：那次 GAN 跑在约 **1.2k~5.5k** 张图上，**不是 50k**（50k 数据集晚 13 小时才生成）
- **判据是坏尺子**：汇报的 0.45 在标签平滑下就是**常数预测器的最优值**，
  既不能证明"没学到"，也不能证明"达到均衡"
- **判别器学得会**：同一份 D、同一 lr，单独训练 **96~99%**；单层线性 **98.4%**
- **文档描述错误**：不是 DCGAN，是**无卷积无 BN 的 2 层 MLP**
- **文档自我矛盾**：`00_已知死路与重启指引.md:42` 说"标准 DCGAN"，
  而 `gan_train.py` 里连一个 conv 都没有

**重新分类**：从「**硬结论：GAN 在此规模不行**」
改为「**未证：一次数据不足、判据失效、描述有误的实验**」。
**不是"值得重试"，而是"必须重做才有结论"。**

> 唯一的**可复现**事实是这一条，它仍然有价值：
> *这个特定的*（2 层 MLP、无正则、G/D 同 lr、1:1 更新、连续 tanh 回归到有序索引）
> 更新规则，会把判别器收敛成常数预测器。
> 而审计实测：**削弱 D 并不能修好它**（lr_D 降到 1e-5、3:1 的 G:D 步数也没用），
> 所以问题很可能在**真假梯度相互抵消**，而不是 D 太强 —— 这是下一轮该针对的地方。

### 4.2 MSE → 条件均值（旧结论：数学必然退化）

**这个结论保留，且是九条里最扎实的一条。** 本次测量独立复现了同一机理（第 3 节）。
它是**损失函数的性质**，与框架无关。

### 4.3 逐像素独立（旧结论：条件独立破坏空间结构）

**保留**，但有重要限定：旧文档据此把「混合近邻」也划为不可接受，
可混合近邻**本身就是逐位置独立的** —— 它成功是因为**逐位置的分布各自都很尖**
（每个位置的颜色来自真实头像），而不是因为它建模了联合分布。
所以正确的表述是：
$$\text{「逐位边缘分布」可以成功，只要每一位的分布足够尖；}\ \text{「逐位均值」必然失败}$$
旧文档把这个区分弄丢了。

### 4.4 其余各条

| 旧死路 | 重新分类 |
|---|---|
| 条件 GAN（调色板当标量） | **工程缺陷**，用 embedding / one-hot 即可修 |
| 自回归（模式崩塌 / exposure bias） | **已知可修**（scheduled sampling、sample-as-training、Gumbel 采样） |
| 蒸馏（逐位置独立 + 教师有噪声） | **工程缺陷**，学生要在教师**自己的输出**上训练 |
| 卷积 v2 白色 bug | **真 bug，已定位并修复**（未知标志通道）—— 这条是干净的工程结论 |
| 混合近邻不可移植红石 | **措辞不准确**：真正缺的是「采样」，见第 3 节 |
