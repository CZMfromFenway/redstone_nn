# 记号总表与步骤清单

**状态**：第 0~6 步已敲定（$D$ 已定死为 $2^b-1$）；第 7 步（模电实现）暂缓。

---

## 一、你确定的符号

### 实数（小写／希腊字母）

| 符号                         | 含义                                         |
| -------------------------- | ------------------------------------------ |
| $x_i$                      | 第 1 层第 $i$ 个输入                             |
| $y_j$                      | 第 1 层第 $j$ 个输出，即第 2 层第 $j$ 个输入             |
| $z_p$                      | 第 2 层第 $p$ 个输出，即像素值                        |
| $u_{j,i}$, $v_{p,j}$       | 两层权重，下标顺序（输出，输入）                           |
| $\theta_j$, $\phi_p$       | 两层偏置                                       |
| $\eta_j$                   | 第 1 层预激活，$y_j=\mathrm{relu}(\eta_j)$       |
| $\Delta=x_{\max}-x_{\min}$ | 输入跨度，$x$ 取 $[-3.5,3.5]$（截断正态的截断点）          |
| **$\alpha_j$**             | **第 $j$ 通道权重缩放因子**                         |
| **$\beta$**                | **整层权重缩放因子**                               |
| **$\delta_j$**             | **第 $j$ 通道实数分辨率**——$Y_j$ 增 1 时 $y_j$ 实际增多少 |
| $\hat x_i$                 | 量化后逆回的实数值（hat 表示逆回）                        |

### 整数（大写字母）

| 符号                       | 含义                                                               |
| ------------------------ | ---------------------------------------------------------------- |
| $b$                      | 全局位宽                                                             |
| $X_i$, $X_i^{(k)}$       | 量化输入及其第 $k$ 位（上标一律位号）                                            |
| $U^{(k)}_{j,i}$          | 第 1 层位权重，$\lvert\cdot\rvert\le882\ (k<b-1)$，最高位到 $2^{31}-1$      |
| $H_j$, $H_{j,\min}$      | $\eta_j$ 的整数版（原始累加）及其最小值                                         |
| $F_j=H_j-H_{j,\min}$     | $\ge0$                                                           |
| **$A_j$**                | **第 $j$ 通道整数 RELU 阈值（整数 RELU 零点）**                               |
| **$c_j$**                | **第 $j$ 通道输出量化步长**                                               |
| $Y_j=\mathrm{RELU}(F_j)$ | 第 1 层整数输出                                                        |
| $V^{(k)}_{p,j}$          | 第 2 层位权重，同约束                                                     |
| $G_p$, $G_{p,\min}$      | 第 2 层原始累加及其最小值                                                   |
| **$B_p$**                | **通道 $p$ 整数截断零点**——$G_p-G_{p,\min}=B_p$ 时 $z_p\approx0$          |
| **$Z_p$**                | **$=\mathrm{CLIP}(G_p-G_{p,\min}-B_p,\ 0,\ 15\beta)$**，第 2 层整数输出 |
| **$\Delta Z$**           | **跨度** $=\max_pZ_p-\min_pZ_p$                                    |
| **$L_p$**                | **级数**，$0\dots15$                                                |

### 运算与约定

| 项 | 含义 |
|---|---|
| $\mathrm{relu}(\cdot)$ | 实数 ReLU |
| $\mathrm{RELU}(\cdot)$ | 整数 RELU，自带两个参数 $A_j,c_j$ |
| $\mathrm{CLIP}(x,l,h)$ | $\min(\max(x,l),h)$ |
| 大小写 | 小写／希腊 = 实数；大写 = 整数 |
| 下标顺序 | （输出，输入） |
| 上标 | 位号 $k$，$k=b-1$ 为高位 |
| hat | 量化后逆回的实数值 |

## 二、已敲定的六步

### 第 0 步　模型

$$\eta_j=\sum_{i=0}^{3}u_{j,i}x_i+\theta_j,\qquad y_j=\mathrm{relu}(\eta_j)$$

$$z_p=\sum_{j=0}^{63}v_{p,j}y_j+\phi_p,\qquad p=0,\dots,31$$

$$\text{像素}=\mathrm{clip}(z_p,0,15)\ \longrightarrow\ \text{逐张 min-max}\ \longrightarrow\ 16\ \text{级}$$

### 第 1 步　输入量化

$$\Delta=7.0,\qquad
X_i=\mathrm{clip}\Bigl(\Bigl\lfloor\frac{x_i-x_{\min}}{\Delta}2^b\Bigr\rfloor,\ 0,\ 2^b-1\Bigr)$$

$$\hat x_i=x_{\min}+\Bigl(X_i+\tfrac12\Bigr)\frac{\Delta}{2^b}$$

> $x_i=x_{\max}$ 时得 $2^b$，截断到 $2^b-1$；故 $\hat x^{\max}=x_{\max}-\dfrac{\Delta}{2^{b+1}}$。

### 第 2 步　第 1 层位权重与累加

$$\boxed{\ \alpha_j=\frac{882}{\max_i\lvert u_{j,i}\rvert\cdot\dfrac{\Delta}{4}}=\frac{3528}{\Delta\cdot\max_i\lvert u_{j,i}\rvert}\ }$$

$$U^{(k)}_{j,i}=\mathrm{round}\Bigl(\alpha_j\,u_{j,i}\,\frac{\Delta}{2^b}\,2^k\Bigr)$$

$$H_j=\sum_{k}\sum_{i}U^{(k)}_{j,i}X^{(k)}_i,\qquad
H_{j,\min}=\sum_{k,i}\min\bigl(0,U^{(k)}_{j,i}\bigr),\qquad
F_j=H_j-H_{j,\min}$$

**实测**：$\alpha_j\in[327.0,2696.5]$；$k<7$ 的最大 $\lvert U\rvert$ 恰为 882，$k=7$ 为 1764。

### 第 3 步　整数 RELU

$$\boxed{\ Y_j=\mathrm{RELU}(F_j)=\mathrm{clip}\Bigl(\Bigl\lfloor\frac{F_j-A_j}{c_j}\Bigr\rfloor,0,2^b-1\Bigr)\ }$$

$$\boxed{\ A_j=\mathrm{round}\bigl(H_j\big|_{\eta_j=0}-H_{j,\min}\bigr)\ }$$

$$\boxed{\ c_j=\Bigl\lceil\frac{F_j^{\max}-A_j}{2^{b}-1}\Bigr\rceil\ },
\qquad
F_j^{\max}=\sum_{k,i}\bigl\lvert U^{(k)}_{j,i}\bigr\rvert$$

> 除数已定死为 $2^b-1$：实测它与 $2^b$ 差 0.01 个百分点，取它可让 $Y_j\le2^b-1$ 由构造保证，不必靠 clip 兜底。**开关 $D$ 已删除。**
>
> $H_j|_{\eta=0}$ 用**约等号**：精确式含尾数 $f_i$ 与权重取整误差，取期望后 $f_i\to\tfrac12$。

**实测**：$A_j\in[1524,6531]$，$c_j\in[10,33]$（中位 **18**），$Y_j$ 实测 $[0,226]$，$Y_j=0$ 占 23.88%（实数网络 $\eta_j<0$ 占 23.35%）。

### 第 4 步　第 2 层位权重与累加

$$\boxed{\ \delta_j=\frac{c_j}{\alpha_j}\ }$$

$$\boxed{\ \beta=\frac{882}{\max_{p,j}\bigl(\lvert v_{p,j}\rvert\delta_j\bigr)\cdot2^{b-2}}\ }$$

$$V^{(k)}_{p,j}=\mathrm{round}\Bigl(\beta\,v_{p,j}\,\delta_j\,2^k\Bigr),
\qquad
G_p=\sum_{k}\sum_{j}V^{(k)}_{p,j}Y^{(k)}_j,
\qquad
G_{p,\min}=\sum_{k,j}\min\bigl(0,V^{(k)}_{p,j}\bigr)$$

**实测**：$\delta_j\in[0.007591,0.051983]$（6.8 倍，而层 1 的输入步长是 1.0 倍）；$\beta=242.744$；**$15\beta=3641$**。

### 第 5 步　第 2 层输出

第 1 层是 $F_j=H_j-H_{j,\min}$ 再过 $\mathrm{RELU}$；第 2 层对称地保留 $G_p-G_{p,\min}$：

$$\boxed{\ B_p=\mathrm{round}\Bigl(-\beta\bigl(\phi_p+\tfrac12\sum_jv_{p,j}\delta_j\bigr)-G_{p,\min}\Bigr)\ }$$

$$B_p\in[5279,\ 12142]\qquad\textbf{恒正}$$

| 成分 | 范围 | 符号 |
|---|---|---|
| $-G_{p,\min}$ | $[5358,\ 12233]$ | 正，主导 |
| $-\beta\bigl(\phi_p+\tfrac12\sum_jv_{p,j}\delta_j\bigr)$ | $[-105,\ -21]$ | 负，量级小 |

$$\boxed{\ Z_p=\mathrm{CLIP}\bigl(G_p-G_{p,\min}-B_p,\ 0,\ 15\beta\bigr)\ }\qquad Z_p\in[0,\ 15\beta]$$

$$Z_p\approx\mathrm{clip}\bigl(\beta z_p,\ 0,\ 15\beta\bigr)=\beta\cdot\mathrm{clip}(z_p,0,15)$$

**把 $B_p$ 放进 clip 内部的好处**：$G_p-G_{p,\min}\ge0$ 与 $B_p>0$ 相减即使为负，**比较器减法模式自带的截断正好等于 CLIP 的下界**，不必单独处理负数。

#### 上界必须是 $15\beta$，不是 $15$

| 上界 | 饱和比例 | $Z_p$ 的不同取值数 |
|---|---:|---:|
| $15$ | **95.13%** | 16 |
| **$15\beta=3641$** | 4.02% | **3642** |

$\beta$ 是"$z$ 每变 1、$G$ 变多少"，$\beta=242.7$。**上界写 15 等于把 $z_p>0.062$ 的全部压平**，$Z_p$ 退化成级数本身，span 无从谈起。

#### $Z_p$ 的理论范围与位宽

未截断的内层量 $G_p-G_{p,\min}-B_p\approx\beta z_p$：

| | 范围 |
|---|---|
| 可达的 $z_p$ | $[-48.70,\ 72.96]$ |
| **$\beta z_p$** | $[-11823,\ +17711]$ |

截断后：

$$\boxed{\ Z_p\in[0,\ 3641]\ \Longrightarrow\ \text{需要 }12\text{ 位}\ (2^{12}=4096)}$$

$$\Delta Z\le3641\ \Longrightarrow\ \text{同样 }12\text{ 位}$$

| 量 | 范围 | 位宽 | 输出 |
|---|---|---:|---|
| $Z_p$ | $[0,3641]$ | **12** | 是 |
| $\Delta Z$ | $\le3641$ | **12** | 是 |
| $G_p-G_{p,\min}$ | $[0,30269]$ | 15 | 否，中间量 |

**$b=8$，$Z_p$ 用 12 位，多出 4 位。** 实测 $\Delta Z$ 中位 2002。

#### 哪些量需要负号

| 符号                                  | 是什么        | 符号性质             |
| ----------------------------------- | ---------- | ---------------- |
| $u_{j,i},\ v_{p,j}$                 | 实数权重       | **可负**           |
| $U^{(k)}_{j,i},\ V^{(k)}_{p,j}$     | 整数位权重      | **可负**           |
| $\eta_j,\ z_p$                      | 实数预激活      | **可负**（纯数学量，不存储） |
| $H_j,\ G_p$                         | 原始累加       | **可负**（硬件靠加常数抬正） |
| $H_{j,\min},\ G_{p,\min}$           | 最小值        | **负**            |
| $x_i,\ X_i$                         | 输入         | 非负               |
| $F_j,\ Y_j$                         | 第 1 层中间与输出 | 非负               |
| $A_j,\ B_p$                         | 零点         | 非负（$B_p$ 实测恒正）   |
| $c_j,\ \alpha_j,\ \beta,\ \delta_j$ | 步长与缩放      | 非负               |
| $Z_p,\ \Delta Z,\ L_p$              | 第 2 层输出与级数 | 非负               |

$$\boxed{\ \text{需要带符号的只有：权重，以及 }H、G\text{ 这一族}\ }$$

### 第 6 步　归一化到 16 级

$$\boxed{\ \Delta Z=\max_pZ_p-\min_pZ_p\ }$$

$$\boxed{\ L_p=\mathrm{clip}\Bigl(\Bigl\lfloor\frac{15\,\bigl(Z_p-\min_pZ_p\bigr)+\lfloor\Delta Z/2\rfloor}{\Delta Z}\Bigr\rfloor,\ 0,\ 15\Bigr)\ }$$

$$\text{方块}_p=\mathrm{LUT}[L_p]$$

$Z_p$ 的零点已是 0、尺度已是 $\beta$，**32 个 $Z_p$ 可直接做 min-max，不需要逐通道再减任何东西。**
