## 一、决策

$$\boxed{\text{本项目采用**数模结合强模网络**（位权重方案），不用强模 LUT}}$$

---

## 二、依据：体积

### 单位体积系数

```
V_bits = 3b · 2n · 2m       = 12 n m b
V_LUT  = 4.5·n·(b/4)·m·32   = 36 n m b
```

$$\text{比值}=\frac{36}{12}=3$$

**三个口径互相印证：**

```
容器/权重     LUT 4b   vs   位权重 b         →  4 : 1
方块³/容器    LUT 9    vs   位权重 12        →  0.75 : 1
体积比 = 4 × 0.75 = 3            ✓
```

而且 LUT 的 9 方块³/容器 与一期文档 `V≈4n·h·L`（L=36）反推的值完全一致。

### 本项目实算（4→64→32）

```
                    层1        层2         合计       LUT 同位宽    比值
b=8/10 单环(定稿)  27,648   270,336    297,984     811,008    2.72
```

$$\boxed{\text{数模结合核心体积约 }3.0\times10^5\text{ 方块}^3,\ \text{LUT 约 }8.1\times10^5}$$

---

## 三、依据：容器利用率

LUT 一列的 15 个容器值**由 1 个整数（斜率）完全决定**：

```
截断类型        列数      每列 15 个容器中的不同值
红石粉（负权重）  11/16     1.82 个        ← 几乎全同
比较器（正权重）   5/16    13.40 个        ← 等差递减
```

$$\boxed{\text{LUT 容器利用率 }1/15=6.7\%\qquad\text{位权重 }b/b=100\%}$$

**但这不算 LUT 的缺陷**——15 个自由容器是"任意单调函数"的票价。
**我们只需要线性，所以 15 个自由度里用了 1 个。**

$$\text{结论：LUT 的通用性对线性权重是纯浪费}$$

---

## 四、LUT 唯一的优势及其代价

$$\text{LUT 的权重量化误差}\approx\text{位权重在 }W_{\text{ref}}=4\times882\text{ 时的水平}$$

**而且 LUT 不需要比较器环**（λ 上限 13455 本来就够）。

| | 强模 LUT | 数模结合 |
|---|---|---|
| 权重误差 | **等效 4×882，无需环** | 需要 96 个环才到 882 |
| 体积 | 3 倍 | **1 倍** |
| 环 | 0 | 96 |

**判决：LUT 的精度优势是"免费的"，但精度已经不是瓶颈**
（位权重方案在 b=8/10 时端到端误差 2.99%，已经够用）。
**而体积是 3 倍、且是实打实的方块。所以选位权重。**

## 六、为什么不是更好的配置

| 备选 | 误差 | 环 | 为什么没选 |
|---|---:|---:|---|
| b=8/10 双环层1 | 1.67% | 128 | 双环布线难度与单环不成比例（你的判断） |
| b_x=10 | 4.63% | 96 | 输入位宽加大反而更差（层1 不是瓶颈） |
| 层2 双环 | 1.67% | 128 | 同上，布线代价 |

**2.99% 已经是"单侧环 + 合理布线"这一档的下限。**
