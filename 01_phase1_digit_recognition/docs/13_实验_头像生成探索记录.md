# 强模 LUT 网络的生成应用：8×8 头像生成（探索记录）

日期：2026-10-05
状态：**暂时封存**

---

# 0. 这份文档是什么

在 `12_强模LUT研究_阶段总结报告.md` 之后，我们尝试了一条**新的应用方向**：

> **用神经网络生成 8×8 像素的玩家头像，训练好后把生成侧网络移植到游戏里。**

**结论：这个方向暂时封存。**

**封存的原因不是"做不到"，而是：**

1. **唯一能生成可辨认头像的方法是"混合近邻"**，而它**不可移植红石**（需要存 5 万张原型表）；
2. **所有可移植的神经方案都能把"逐像素统计"学好（准确率最高到 0.677），但生成的图像视觉上不合格**；
3. 根本困难在于：**8×8×16 色的离散空间里，"统计正确"不等于"视觉合理"**。

**但这次探索产生了若干确定有效的成果**（调色板、超立方体排列、对称分解分析、数据管线），
这些都记录在 `14_附录`。

# 1. 任务定义

| 项 | 设定 |
|---|---|
| 目标 | 无条件生成 8×8 像素玩家头像 |
| 分辨率 | **8×8**（最终分辨率，不再放大） |
| 颜色 | **16 色**（后扩到 48 色对比） |
| 生成侧 | 条件/无条件 GAN、自回归、蒸馏、近邻——全部试过 |
| 部署 | 离线训练，把前向网络移植到红石 |
| **约束** | 网络结构需**可移植红石**（前馈、扇入有限） |

**为什么是 8×8**：MC 皮肤是 64×64 的模型展开图，其中**脸部恰好是 $8\times8$**
（坐标 `(8,8)-(16,16)`），这是天然的"头像"区域。

# 3. 试过的八种方案（完整记录）

## 3.1 汇总表

| # | 方案 | 最好的数值指标 | 生成图像 | 可移植红石 |
|---|---|---|---|---|
| 1 | 无条件 GAN | 判别器不学 | ✗ 噪点 | ✓ |
| 2 | 朴素贝叶斯混合模型 | 测试 LL 恶化 | ✗ 噪点 | ✓ |
| 3 | 条件 GAN（标量索引） | L1 = 0.101 | ✗ 噪点 | ✓ |
| 4 | 自回归（光栅顺序） | 准确率 0.537 | ✗ 噪点 | ✓ |
| 5 | 自回归（任意顺序 + 置信度填充） | 准确率 0.541 | ✗ 模式崩塌 | ✓ |
| 6 | 自回归（5 万张） | **准确率 0.704** | ✗ 模式崩塌 | ✓ |
| 7 | 蒸馏（逐位置独立） | **准确率 0.758** | ✗ 马赛克 | ✓ |
| 8 | **卷积 v3（未知标志 + 对称 + HSL）** | **准确率 0.677** | ✗ 有结构，非脸 | ✓ |
| 9 | **混合近邻 + 对称约束** | — | **✓ 可辨认！** | **✗** |

## 3.2 方案 1：无条件 GAN

**结构**：$z(32)\to128\to64$，判别器 $64\to64\to1$，非饱和损失。

**结果**：6000 epoch 后 $D(\text{真})=D(\text{假})=0.45$，**判别器完全没学到**，输出噪点。

**重要**：**梯度检验证明实现无误**（解析梯度 vs 数值梯度误差 $10^{-8}$；
单独训练判别器能把真假分开到 0.90 / 0.0002）。

**结论**：**不是 bug，是 GAN 动力学问题**——判别器一步就能压制生成器。

## 3.3 方案 2：朴素贝叶斯混合模型

$$p(x)=\sum_k\pi_k\prod_{i=1}^{64}p_{k,i}(x_i)$$

| $K$ | 训练 LL | **测试 LL** | 生成图颜色数（真实 5.29） |
|---:|---:|---:|---:|
| 50 | −95.9 | **−110.4** | 10.77 |
| 1000 | −48.4 | **−134.1** | 8.49 |

**失败原因**：**64 像素条件独立**的假设破坏了空间结构。
"眼睛是成对的、头发是连续的"这些相关性被丢弃，所以每像素各抽各的 → 噪点。

## 3.4 方案 3：条件 GAN

$$x_{\text{in}}\to\text{Encoder}\to z\to\text{Decoder}\to\hat x$$

判别器判断**配对** $(x_{\text{in}},\hat x)$ 是否真实。

**结果**：判别器真的学到了（$D(\text{真})=0.897$，$D(\text{假})=0.002$），
重建 L1 从 0.52 降到 **0.118**，但输出仍是噪点。

**根因**：把**调色板索引当标量**喂进网络。索引是有序序号，但网络做**加权求和**：
$0.5\times\text{红}(5)+0.5\times\text{橙}(6)=5.5$ 在颜色上无意义。

**修正尝试**（one-hot，1024 维输入）：计算量太大，3000 epoch 需十几小时，放弃。

## 3.5 方案 4~6：自回归

$$p(x)=\prod_{i=1}^{64}p(x_i\mid x_{<i})$$

| 版本 | 生成顺序 | 结果 |
|---|---|---|
| v1 | 光栅 | 噪点（预测第 8 个像素时右边全未知） |
| v2 | **置信度填充**（每轮填最确定的位置） | **模式崩塌**：60 张图几乎完全相同 |
| v2 修正 | **随机填充** | 噪点 |
| 5 万张数据 | 置信度填充 | 准确率 **0.704**，但崩塌更严重 |

**两个关键教训**：

**教训一：指标会骗人。** 崩塌那批的"颜色数 5.08"（真实 5.33）看着正常，
实际是"深色块 + 浅色块"凑出来的。**必须加"样本间多样性"指标**才能看出问题。

**教训二：训练目标与生成过程不匹配。** 训练时"挖掉 1 个像素、给其余 63 个"，
但生成时早期步骤**几乎没有任何已知像素**——模型在这种低上下文条件下只学会输出众数。

## 3.6 方案 7：蒸馏

**思路**：既然混合近邻能出好图，就用它生成大量配对 $(x,x')$，训练前馈网络模仿。

$$\text{输入}=x(64)\ +\ \text{位置 one-hot}(64)=128\to256\to16\ \text{logits}$$

**训练非常成功**：

| 指标 | 值 | 均匀基线 |
|---|---:|---:|
| 验证交叉熵 | **0.812** | 2.7726 |
| 验证逐像素准确率 | **0.758** | 0.0625 |

**但生成不行**：精修教师输出时要改动 **34.8/64** 像素，反复迭代**发散**（36→51 像素）。

**三条根因**：
1. 训练输入是**真实头像**，使用时喂**教师生成的图**——分布不匹配；
2. **逐位置独立预测**产生马赛克（空间一致性无约束）；
3. **教师本身在 $T=5$ 就有噪声**，学生学得越准越像噪声。

## 3.7 方案 8：卷积式学生（最终版本）

**三个设计决定**：

| 设计 | 目的 |
|---|---|
| **3×3 局部感受野** | 相邻输出共享输入邻域 → 空间一致；红石扇入从 64 降到 9 |
| **对称/反对称分解** | 只预测左半 32 个位置，右半由 $s+d$ 合成 |
| **HSL 三通道**（辅助监督） | 用 H/S/L 而非 16 路 one-hot，网络可在颜色间插值 |

**失败版本（v1）**：用 MSE 回归 HSL。

| 迭代 | 颜色数 | 对称率 |
|---:|---:|---:|
| 1 | 8.38 | 0.74 |
| 2 | 4.28 | 0.91 |
| **4~8** | **2.00** | 0.97 |

**失败原因**：MSE 目标 → 网络学的是**条件均值** → 反复应用均值算子 = **不断模糊** → 收敛到常数。

$$\text{预测均值}\ \ne\ \text{采样分布}$$

**修正（v2）**：改成**掩码分类**（16 色交叉熵），生成时**采样**。

| 版本 | 逐像素准确率 | 训练 CE | 中轴线白色（真实 7.32%） |
|---|---:|---:|---:|
| v2 | 0.567 | 1.442 | **25.81%** ← bug |
| **v3** | **0.677** | **1.095** | **9.77%** ✓ |

**v2 的 bug（由 czm 观察发现）**：编码冲突。

$$\text{白色(0号) one-hot}=\bigl[+1,\underbrace{-1,\dots,-1}_{15}\bigr]\qquad
\text{"未知"写入}=\bigl[-1,-1,\dots,-1\bigr]$$

**两者共享 15 个 $-1$ 通道。** 而训练时"未知"出现频率（31%）是"真实白色"（8%）的 **4 倍**，
所以模型把"全 $-1$"学成了白色 → 生成时从全未知开始 → 中轴线填满白色。

**修正**：给每个邻域像素加一条独立的**未知标志通道**，输入 $176\to185$ 维。
**准确率立刻从 0.567 提到 0.677。**

**但视觉上仍不合格**——有结构（深色在上、肤色在中），但形不成清晰五官。

## 3.8 方案 9：混合近邻 + 对称约束（唯一成功的）

### 模型

$$p(x)=\sum_k\pi_k p_k(x)$$

每个"成分"以**一个真实头像为原子**：

1. 随机取一个原型 $a$；
2. 在 $(s,d)$ 联合空间找 $k=30$ 个最近邻（汉明距离）；
3. 逐位置按距离加权采样颜色：$w_j\propto\exp(-d(a,a_j)/\tau)$。

**为什么它保住了空间结构**：位置 $i$ 的颜色**只能来自真实头像在位置 $i$ 的颜色**。
如果原型是棕发，邻居在头发位置也大多是棕色 → 抽出来仍是连续的一块。

### 对称约束（czm 的提议）

**问题**：64 个位置**独立采样** → 左右眼是两个独立随机事件 → 温度一高就"一高一低"。

$$P(\text{左右一致})=1-(1-p)\ \Longrightarrow\ \text{温度越高越不对称}$$

**修正**：按左右镜像配对成 **32 对**，每对**一起采样**。

### 结果

| 配置 | 颜色数（真实 5.29） | 多样性（真实 57.8） | 对称率（真实 0.859） | 新颖性 |
|---|---:|---:|---:|---:|
| $T=0.5$ 无约束 | 5.22 | 57.8 | 0.85 | **0.0**（复制） |
| $T=5.0$ 无约束 | 5.72 | 57.7 | **0.78** ✗ | 4.2 |
| **$T=5.0$ 完全对称** | **5.09** | 57.7 | **1.00** | 6.6 |
| **$T=30$ 完全对称** | 5.23 | 57.6 | **1.00** | **13.0** |

**关键发现**：**对称约束把"温度"和"空间一致性"解耦了。**

| 旋钮 | 控制什么 |
|---|---|
| 温度 $T$ | 变化**幅度**（新颖性） |
| **对称约束** | 变化**空间一致性** |

**不分解时两者绑定**（提高温度必然破坏对称）；**分解后可以独立调节**。

**$T$ 从 5 涨到 30（6 倍），新颖性从 6.6 涨到 13.0，而颜色数几乎不变（5.09→5.23）。**

# 4. 为什么封存

## 4.1 核心矛盾

$$\underbrace{\text{能生成可辨认头像}}_{\text{混合近邻法}}\ \text{不可移植红石}
\qquad
\underbrace{\text{可移植}}_{\text{神经模型}}\ \text{视觉不合格}$$

## 4.2 更深的原因

| 观察 | 说明 |
|---|---|
| **统计正确 ≠ 视觉合理** | 卷积 v3 逐像素准确率 **0.677 > 混合近邻的约 0.5**，但视觉上前者远不如后者 |
| 原因 | 近邻法取色**总是来自某个真实头像的局部**；神经网络会产生**训练集里不存在的像素组合** |
| 后果 | 这些组合在数字上"符合边缘分布"，但视觉上不协调 |

**这是 8×8×16 色离散空间的固有困难**——它太小，样本太稀疏，
"符合统计"的方案太多，而"视觉合理"的只是其中一个子集。

## 4.3 与主项目的关系

**这次探索与强模 LUT 的关系**：

| | 强模 LUT 路线 | 本次生成路线 |
|---|---|---|
| 数学基础 | 需要（16 容器、步长、闭式解） | **基本不需要** |
| 移植方式 | 强模 LUT 单元 | 纯前馈网络 |
| 生存模式可复现 | **不可**（已因此封存） | 取决于具体结构 |

**所以这次探索实际上绕开了强模** —— 而强模本身已因"生存模式无法复现"而封存。
**两条线叠加，整个方向的价值都受限。**

# 5. 如果以后要继续

## 5.1 最可能成功的方向

**接受混合近邻法作为生成方案，放弃红石移植。**

理由：

| | 混合近邻 |
|---|---|
| 质量 | **可辨认**（唯一达到的） |
| 多样性 | 57.7（真实 57.8） |
| 颜色分布 | 5.31（真实 5.29） |
| 对称性 | 可精确控制（0.78~1.00） |
| 速度 | 400 张/秒 |
| **代价** | 需存 5 万张原型表（约 3 MB） |

**如果"生成头像"本身是目标（而非红石实现），这条路已经走通了。**

## 5.2 若要继续攻神经网络方案

| 方向 | 说明 |
|---|---|
| **加入局部一致性损失** | 惩罚"训练集里不存在的像素组合" |
| **用更小的感受野 + 更多轮** | 强制网络只学局部统计 |
| **在 $(s,d)$ 空间上分别建模** | $d$ 极度稀疏（86% 为零），可单独用极小的网络 |
| **提高分辨率** | 8×8 可能本身就太小，语义结构无法表达 |
