# 一、已经确定的事实（不要再推翻）

## 1.1 位宽

$$\boxed{b=8\ \text{（两层统一）}}$$

`docs/39` 里的 $b_y=10$ 已作废，见该文件顶部修订。

## 1.2 火把激活规则

$$\boxed{\text{火把亮}\iff X_i^{(k)}\ne\bigl[W^{(k)}_i>0\bigr]}$$

$$W>0:\ \text{位}=0\ \text{亮};\qquad W<0:\ \text{位}=1\ \text{亮}$$

推导见 `docs/40` §0.0。

## 1.3 输入

$$X_i\in[0,255]\ \text{（层1）},\qquad X_i=\sum_k X_i^{(k)}2^k$$

**输入是 4 个整数，不是 4 个 0/1。**

## 1.4 容器编码

$$\text{signal}=1+\left\lfloor\frac{14U}{27}\right\rfloor,\qquad U=\Sigma\,\text{count}$$

用**木斧**（maxStack=1），每格 `count ≤ 64`，27 格。

$$\text{上限 }897=1+\lfloor14\times27\times64/27\rfloor$$

```nbt
Items:[{Slot:0b,count:64b,id:"minecraft:wooden_axe"}, … ]
CustomName:'"signal: S, item: Nx64"'
```

## 1.5 比较器

```nbt
方块状态：comparator[facing=FLIP[out],mode=…,powered=<state>0 ? true : false>]
BlockEntity：{ Id:"minecraft:comparator", Pos:[x,y,z],
               Data:{ id:"minecraft:comparator", OutputSignal:<int> } }
```

$$\boxed{\texttt{OutputSignal}\ \text{上限 }2^{31}-1\ \text{（不是 15）}}$$

$$\boxed{\texttt{powered}\ \text{必须与 OutputSignal 一致 —— 全写 false 会让环失效}}$$

## 1.6 多充能取最大

$$\text{方块被两个比较器充能}\Rightarrow\text{读它的比较器看到较大的那个}$$

优先级：火把 > 中继器 > 红石粉 > 比较器。求值器已经实现（`chargeOf` 取 max）。

# 三、🔴 第一优先级：配对区"情形Ⅱ"未实现（✅ 已完成，见 docs/42）

## 3.1 三种方案（文档定义）

| 情形 | 条件 | 正确结构 |
|---|---|---|
| **Ⅲ** | $\lvert W\rvert$ 两路都 $\le882$ | 双直通桶，无环 |
| **Ⅰ** | 两路都 $>882$ | 单环 + Δ桶 + 减法 |
| **Ⅱ** | 一路 $>882$ | **单环 + 直通桶**（小值直接进桶）|

$$\boxed{\text{情形Ⅱ 我根本没有实现 —— 和情形Ⅰ 走了同一条路}}$$

## 3.2 后果（实测）

`results/schem/layer1_stack64.schem` 里 **47 个 Δ 桶不可达**，最大 1761：

$$\Delta=\lvert W_{\text{big}}\rvert-\lvert W_{\text{small}}\rvert$$
$$\text{情形Ⅰ}:\ \Delta<1764-882=882\ \checkmark$$
$$\text{情形Ⅱ}:\ \Delta\ \text{可到 }1749\ \times$$

## 3.3 当前代码（`viewer/plane_sim.html` 约 215–257 行）

```js
const cs = lo>882?'I':(hi>882?'II':'III');
```

## 3.4 试过但失败的改法

$$\text{只把 } \texttt{bar(xa+1,zr)} \text{ 包成 } \texttt{if(cs==='I')} \Rightarrow \textbf{768/1536}$$

原因：小值列的梯子仍在通过减法取数，Δ 一没了就输出 $S_{\text{big}}$。

## 3.5 正确的改法（下一次照这个做）

$$\boxed{\text{不是删 Δ 桶，而是给小值列换一条独立的"直通桶"梯子}}$$

```
情形Ⅱ：
  大值列 (bigCol)：保持环路径
      (bigCol,zr+2) 导线 ← 环路径充能
      (bigCol,zr+1) N    ← 读 (bigCol,zr+2)
      (bigCol,zr)   N    ← 充能 MSB 块

  小值列 (smlCol)：完全独立
      bar(smlCol, zr+1, S_small)     ← 直通桶，S≤897 一定放得下
      (smlCol,zr) N                  ← 直接读该桶

  不建：Δ 桶、减法器、(xa+1,zr+1) 的 N 比较器、(smlCol,zr+2) 的导线
```

**注意**：现在的梯子是三列共享的（`xa / xa+1 / xb`），改的时候要按情形分支，让两列各走各的。
