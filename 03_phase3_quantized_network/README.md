## 任务

研究出一套方法论，把二期得到的最终模型移植成红石结构，并且这套方法能复用到以后的其他模型。

交付物是一段可重复执行的流程、一个能提前算出成本的模型、一种无需实际建造就能验证网表的方法。具体装置只是这套流程的一次实例化。

$$\text{模型描述} \longrightarrow \text{量化方案} \longrightarrow \text{网表} \longrightarrow \text{成本与精度报告} \longrightarrow \text{建造}$$

| P4 | 方法论固化 | 未开始 |

P0 的两个结论已改变 P1 的做法：

1. **位宽是唯一杠杆。** 量化误差在所有层、所有部件上都按 $2^{-b}$ 下降，与分布形状无关（4 bit 时相对 RMS 误差 0.041，8 bit 时 0.0023）。所以 P1 要扫的是一个标量，不是逐层的一张表。
2. **输出量化必须覆盖原始 38.6 跨度，不能按 0..15 设计。** clip 是后处理的一环，clip 之前的误差会移动拉伸参照点。

## 方案已定

本期**只做强模**，接受"不能上 MCHPRS、生存模式无法制造"的代价。

$$	ext{数电输入} 	o 	ext{强模编码} 	o 	ext{强模求和} 	o 	ext{强模转数电输出} 	o 	ext{数电传输}$$

这是一期已识别但未研发的构型。选它的两条理由：它允许用多于 4 位近似神经元输出，而二期灰度模型的输出跨度是 38.6 的连续值；它只要求 ReLU，而二期模型全部是 ReLU。数电传输还消掉了一期"强模只能水平传输"的约束，那正是上一代成品里转接重排占 81% 体积的原因。

P1 的核心问题是层间位宽与 LUT 条目数的权衡：单元条目数等于输入电平数，位宽翻倍要么让单体体积涨 16 倍，要么用拆分结构让单元数翻倍。

全数电方案在原理上也可行（2,304 次乘法已进入数电可接受范围），本期不做，触发重估的条件写在 `docs/02_架构定案.md` 第六节。
