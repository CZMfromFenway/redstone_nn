# 风格开关、小网络的细节、彩色两阶段方案

## 一、你的判断是对的：线性纯化是"风格开关"

对每个风格单独拟合一个线性探针（该类 vs 其余），5 折交叉验证：

| 目标 | 正例 | cv AUC | 方向（旋钮权重） |
|---|---:|---:|---|
| **类二次元 vs 其他** | 53 | **0.896** | PC1 **−0.28**、PC2 −0.16 |
| **类三次元 vs 其他** | 13 | **0.890** | PC2 **+0.12** |
| **类游戏 vs 其他** | 37 | 0.735 | PC1 **+0.16** |
| **可接受 vs 中/差** | 103 | **0.543** | — |
| 中/差 vs 可接受 | 50 | 0.543 | — |

**三种风格都是线性可分的，而且方向几乎构成一组基：**

- **类二次元** = PC1 低、PC2 低
- **类游戏** = PC1 高
- **类三次元** = PC2 高

所以"打开它 → 更像二次元"是成立的（AUC 0.896，方向明确）。
同理可以做出"类游戏开关"、"类三次元开关"，甚至"去二次元"（把 PC1/PC2 往上推）。

**但"排斥中/差"这条线性路完全失败（0.543）。**

### 中/差 也不是"离平均脸太远"

| 标量判据 | AUC |
|---|---:|
| \|PC3\| | 0.609 |
| 最大 \|PC\| | 0.528 |
| PC0-3 半径 | 0.522 |
| \|PC2\| | 0.458 |
| PC1-2 半径 | 0.399 |
| \|PC1\| | **0.372**（越大反而越可接受）|

**没有任何一个标量能分开中/差。**

图：`results/style5/STYLE_PLANE.png` 把每张脸画在 (PC1, PC2) 平面上——
类二次元集中在左半、类游戏在右半、类三次元在顶部，而**中/差撒得到处都是**。

**结论：风格是方向，可接受性不是。**

## 二、小网络是什么、怎么算、多大规模

### 结构

```
输入 4 个数（PC0..PC3）
   ↓  16 个神经元，每个都是 4 个输入的加权和 + 偏置
   ↓  ReLU：负数变 0（16 次比较）
   ↓  1 个输出 = 16 个隐含值的加权和 + 偏置
   ↓  sigmoid → "可接受"的概率
```

### 具体运算

**第一层**（4 → 16）：
$$h_j = \max\left(0,\ \sum_{i=0}^{3} W_{ji}\,x_i + b_j\right),\quad j=0..15$$

- **4 × 16 = 64 次乘加**，16 次比较（ReLU）

**第二层**（16 → 1）：
$$y = \sum_{j=0}^{15} v_j\,h_j + c$$

- **16 次乘加**

**合计：80 次乘加 + 16 次比较，97 个参数**（W 64 + b 16 + v 16 + c 1）

### 训练
- 损失：二元交叉熵（可接受 = 1）
- 优化器：Adam，lr 0.02，weight decay 1e-3
- 400 步，5 折交叉验证
- 每折只用训练折拟合，验证折打分 → **AUC 0.690**

### 为什么它能行而线性不行
16 个 ReLU 神经元把输入空间切成许多线性区域，边界可以是**折线**而不是一条直线。
"可接受/中差"的边界正是这种形状。

### 但红石上我建议用二次型，而不是这个网络

| 方案 | AUC | 红石成本 |
|---|---:|---|
| 线性 | 0.543 | 5 次乘加 |
| **二次型（14 特征）** | **0.683** | **约 20 次乘加**（4 个平方 + 6 个两两乘积 + 14 项点积） |
| 4-16-1 网络 | 0.690 | 80 次乘加 + 16 个比较器（ReLU） |

**二次型几乎一样准（0.683 vs 0.690），成本只要四分之一，而且只需要乘法器，不需要比较器。**

二次型的形式：

$$y = c + \sum_i a_i x_i + \sum_i b_i x_i^2 + \sum_{i<j} d_{ij}\, x_i x_j$$

4 个输入 → 4 个一次项 + 4 个平方项 + 6 个交叉项 = **14 项**。

## 三、彩色：你的两阶段方案成立，而且比"只用颜色PCA"更好

先纠正我上一条的说法：我说"明度推不出颜色"是对的，但**你的方案里第二阶段还接收颜色 PCA**，所以结论不同。

颜色 PCA（RGB 图像 192 维）：前 8 维解释 75.1%，16 维 86.2%，22 维 90.8%。

### 第二阶段预测能力（线性读出 R²）

| 输入 | 饱和度 | 色相 |
|---|---:|---:|
| **灰阶 32 维（无颜色信息）** | 0.071 | 0.063 |
| 颜色 PCA 4 维 | 0.102 | 0.182 |
| 颜色 PCA 8 维 | 0.118 | 0.292 |
| 颜色 PCA 16 维 | 0.135 | 0.314 |
| **灰阶 32 + 颜色 4 维** | **0.134** | **0.315** |
| **灰阶 32 + 颜色 8 维** | **0.138** | **0.340** |
| **灰阶 32 + 颜色 16 维** | **0.153** | **0.369** |

**两点关键：**

1. **灰阶确实有用**：颜色 PCA 4 维单独预测色相只有 0.182，加上灰阶跃升到 **0.315**。
   原因是颜色 PCA 给"全局色调"，灰阶图告诉模型"这是哪张脸"，两者协同。
2. **饱和度极难预测**（最高 0.153）。色相相对可预测（0.37）。

**注意这些是线性读出的下限**——第一阶段我们见过线性 0.543 → 网络 0.690 的跃升。
所以真实网络能做到更高，值得实做。

### 因此推荐方案

$$\text{阶段1：4 个灰阶 PCA} \to \text{32 级灰度图}\quad(\text{已有，74,752 乘法})$$
$$\text{阶段2：[32 灰度} + k \text{ 个颜色 PCA]} \to \text{饱和度}(32) + \text{色相}(32)$$

取 $k=8$：阶段 2 输入 40 维，若隐藏层 64：
$$40\times64 + 64\times64 = 6{,}656\ \text{乘法}$$

**总成本 ≈ 81,000 乘法**，仍然是原始 512 输出模型（202,240）的 40%。

### 与"一次性给所有 PCA"的对比

$$\text{联合方案：4 灰阶 + 8 颜色} \to \text{隐藏}64 \to \text{明度}32+S32+H32$$
$$12\times64 + 64\times96 = 6{,}912\ \text{乘法}$$

**两者成本几乎相同。** 两阶段的优势是**复用已训好的阶段 1**，而且红石上可以只做灰度版（跳过阶段 2）；联合方案的优势是一次训练、三路输出互相约束。

**建议先做两阶段**，因为阶段 1 已经验证过 58.8% → 88.7%，风险低。
