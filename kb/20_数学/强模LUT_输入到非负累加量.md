# 强模 LUT：从输入量化到非负累加量 $N$

状态: 待验
可信度: 推导 + 数值验证（本文档的公式均有穷举核对记录）
最后核实: 2026-10-31
适用: **强模 LUT 构型**（每个输入一条 16 项单调阶梯，不拆位）；任意 MLP 任意一层的矩阵乘法部分；本页只到 $N_j$

---

## 引言

强模 LUT 与数模结合是两种构型，差别在“一个权重怎么存”：

| | 数模结合 | **强模 LUT** |
|---|---|---|
| 权重怎么存 | 拆成 $b$ 个位权重，每位一个容器 | **一条 16 项阶梯**，每项一个容器 |
| 一个权重用几个容器 | $b$ 个 | **16 个**（固定，与权重大小无关） |
| 输入分辨率 | 逐层位宽 $b$，可到 8、12 | **每条线只有 16 级**，要更细就拆线 |
| 运行期运算 | 按位相加 | 读出阶梯值再相加 |

所以这一页的链条是：**量化输入（16 级）→ 用斜率编码权重、定出阶梯 → 把阶梯反解成 16 个容器值 → 累加 → 折叠 → 抬成非负数**。

“折叠”是这一构型特有的步骤，原因在 §四：阶梯的绝对值很大，不折叠的话常数会把量化分辨率吃光。

> **强模 LUT 是另一种构型，本页的算法不适用于数模结合**（那边是位权重那一套）。

---

## 符号

下标顺序（输出，输入），上标为位号或档位号。

| 符号 | 含义 | 取值/说明 |
|---|---|---|
| $x_i$ | 第 $i$ 个实数输入 | |
| $X_i$ | 量化后的输入整数 | **$0\sim15$**（这条线只有 16 级） |
| $\Delta_i$ | 第 $i$ 个输入的跨度 | |
| $\delta_i$ | 每级对应多少实数 $\Delta_i/16$ | 注意分母是 16，不是 $2^b$ |
| $\rho_{j,i}$ | 第 $(j,i)$ 个阶梯的**斜率** | 由权重与 $\Lambda_{\max}$ 定 |
| $\Lambda_{\max}$ | 单条阶梯的总升幅上限 | $\le868$ |
| $\lambda_{j,i}(x)$ | 阶梯函数：输入为 $x$ 时该单元的输出 | 整数，$\ge0$ |
| $V^{(k)}_{j,i}$ | **容器值**：第 $k$ 档那个容器里放的内容 | $0\sim897$ |
| $\Lambda_j$ | 该神经元的**原始累加** $\sum_i\lambda_{j,i}(X_i)$ | 整数，$\ge0$ |
| $Q_j$ | **折叠后**的累加 | 可正可负 |
| $Q_{j,\min}$ | $Q_j$ 的最小可能值 | $\le0$ |
| $N_j$ | **非负累加量** $Q_j-Q_{j,\min}$ | $\ge0$ |
| $\kappa_j$ | 把 $N_j$ 换回实数的比例系数 | 见 §四 |

## 一、输入量化：每条线只有 16 级

$$X_i=\mathrm{clip}\!\left(\left\lfloor\frac{x_i-x_{i,\min}}{\Delta_i}\,16\right\rfloor,\ 0,\ 15\right)$$

$$\delta_i=\frac{\Delta_i}{16},\qquad \hat x_i=x_{i,\min}+\Bigl(X_i+\tfrac12\Bigr)\delta_i$$

**这是这一构型最硬的限制**：一条阶梯只有 16 个条目，所以一条输入线只能表达 16 级。
量化误差 $\epsilon_x=\dfrac{1}{2\cdot16}=\dfrac{1}{32}$——固定，不随网络变。

要更细的输入，就把一个数拆成多条弱模线（典型是两条：高半字节、低半字节，权重比 $16:1$）。
**拆线只发生在输入侧**：拆成几条，就需要几套阶梯，单元数按倍数增加。

> 与数模结合对比：那边一条线就能承载 $b$ 位（8 位就是 256 级），代价是每个权重变成 $b$ 个容器；
> 这边一条线只有 16 级，但一个权重只要 16 个容器（与权重幅值无关）。

## 二、用斜率编码权重

一个权重 $w_{j,i}$ 被编码成一条阶梯：**输入每涨一级，输出涨（或降）$\rho_{j,i}$**。

$$\lambda_{j,i}(x)=\mathrm{round}\bigl(x\,\rho_{j,i}\bigr)\quad(w_{j,i}>0)$$

$$\lambda_{j,i}(x)=\mathrm{round}\bigl((15-x)\,\rho_{j,i}\bigr)\quad(w_{j,i}<0)$$

两条铁律：

1. **浮动步长**：只对累加值取整（$\mathrm{round}(x\rho)$），**不要**先把 $\rho$ 取整成常数步长。
   后者会引入随 $x$ 累积的误差，最坏 $15\times0.5=7.5$；浮动步长的误差处处被 $0.5$ 咬住。
2. **逐坐标按最大权重定斜率**：

$$\rho_{j,i}=\Lambda_{\max}\cdot\frac{\lvert w_{j,i}\rvert}{\max_i\lvert w_{j,i}\rvert},\qquad \Lambda_{\max}\le868$$

让 $\lvert w\rvert$ 最大的那一路用满容器上限，其余按比例缩。
**不是**所有坐标共用一个斜率——那会让小权重坐标损失大量分辨率。

### 为什么是 868

阶梯的相邻差由容器内容决定，而两种截断方式给出的窗口不同：

| 截断方式 | 顺式步长 $\Delta\lambda$ | 由 $V\in[0,897]$ 推出的界限 |
|---|---|---|
| 红石粉 | $15-V$ | $-882\le\Delta\lambda\le+15$ |
| 比较器 | $(29-x)-V$ | $-868\le\Delta\lambda\le29-x$ |

两种截断在实际布线里会交替出现，所以取**交集**：

$$\boxed{\ \lvert\Delta\lambda\rvert\le868\ }$$

这就是 $\Lambda_{\max}=868$ 的来历——它不是一个新常数，而是“两种截断都能实现”的交集。

---

## 三、容器值：$V=15-\Delta\lambda$（顺式）

记第 $k$ 档的步长为 $\Delta\lambda^{(k)}=\lambda(k+1)-\lambda(k)$，则该档容器里放的是

$$V^{(k)}=15-\Delta\lambda^{(k)}\quad(\text{红石粉}),\qquad
V^{(k)}=(29-k)-\Delta\lambda^{(k)}\quad(\text{比较器})$$

- **上升阶梯**（正权重，每步 $+\rho$）：$V=15-\rho$ 会变成负数，所以上升阶梯必须走**反式接线**，
  此时等价于 $V=15+\rho\le897\Rightarrow\rho\le882$；
- **下降阶梯**（负权重，每步 $-\rho$）：$V=15+\rho\le897\Rightarrow\rho\le882$。

加上 §二 的交集约束，实际取 $\rho\le868$。于是所有容器都落在 $[0,897]$ 内，**不需要比较器环**——
这就是 LUT 构型的一个好处：环的问题被“16 个容器分摊”掉了（每个容器只承担一步，最大值有限）。

> 单元里有 16 个容器，但只有 15 个步长：$x=0$ 那一档只贡献一个常数，用来把阶梯的高度对齐到
> $\lambda(0)=0$（正权重）或 $\lambda(15)=0$（负权重）。**对齐之后 $\lambda\ge0$ 恒成立**，
> 因为比较器不能输出负信号。

## 四、累加、折叠、非负化

### 4.1 原始累加

$$\Lambda_j=\sum_i\lambda_{j,i}(X_i)$$

$\Lambda_j\ge0$ 天然成立（每个 $\lambda\ge0$）。但它带着一个**巨大的常数**：

$$\Lambda_j=\underbrace{\sum_i\lambda_{j,i}(0)}_{\text{常数, 可达数万}}+\sum_i\bigl[\lambda_{j,i}(X_i)-\lambda_{j,i}(0)\bigr]$$

常数项随输入条数线性增长，输入一多就是数万量级。**而量化步长必须覆盖整个量程**，
于是分辨率被这个常数吃光——实测误差可到量程的 58%。

### 4.2 折叠

把每个坐标的初值减掉：

$$\boxed{\ Q_j=\sum_i\bigl[\lambda_{j,i}(X_i)-\lambda_{j,i}(0)\bigr]\ }$$

折叠的意义不是“把数变小”，而是**让那个常数变成精确的偏置**：它不再参与量化，
只是一个平移量。折叠后误差降到 $0.0035$（相对 $u$ 的量程）。

实现上也不额外花钱：正权重的 $\lambda(0)=0$，负权重的 $\lambda(0)=15\rho$，
两者都是**已知常数**，物理上就是把阈值整体挪一下。

### 4.3 抬成非负数

折叠后 $Q_j$ 可正可负：正权重贡献 $[0,15\rho]$，负权重贡献 $[-15\rho,0]$。所以

$$Q_{j,\min}=-\sum_{i:\,w_{j,i}<0}15\rho_{j,i},\qquad
Q_{j,\max}=\sum_{i:\,w_{j,i}>0}15\rho_{j,i}$$

$$\boxed{\ N_j=Q_j-Q_{j,\min}\ \ge 0\ }$$

$N_j$ 的范围是 $[0,\ \sum_i 15\rho_{j,i}]$。平移量 $-Q_{j,\min}$ 是一个纯常数，
同样由阈值吸收——**它不改变任何量化精度**。

把 $N_j$ 换回实数时用一个比例系数：

$$u_j=\kappa_j\,N_j+\theta'_j,\qquad \kappa_j=\frac{\max_i\lvert w_{j,i}\rvert}{868}$$

$\theta'_j$ 把 $-Q_{j,\min}$ 与原来的偏置一起吸收。**$\theta'_j$ 是下一节（零点）的事，本页不管。**

> **这几层累加量里，只有最后那个非负值是真实存在的信号。**
> $\Lambda_j$、$Q_j$ 是为陈述算法而引入的记账量：折叠与平移在电路上不是“减一个数”，
> 而是折进初始常数与阈值里（第 0 号容器、减法链的偏置）。所以电路里走的就是一个非负值，
> 具体怎么把它摆进结构，属于 schem 编译的事，本页不展开。

## 五、代价与边界

- **每个权重 16 个容器**，与权重幅值无关——这是 LUT 构型的标志性性质。
- 单元体积只取决于 **输入条数 × 神经元数**，不取决于权重多大。
- 只有当**一步的绝对值**要超过 868（即某个权重要比其他权重大得多、或者 $\Lambda_{\max}$ 顶格还不够）时，
  才需要比较器环接力。
- 输入分辨率被 16 级限制；要更细只能拆线，拆几条就乘几套阶梯。

$$\text{容器数}=16\times n\times m\quad(n\ \text{输入条数},\ m\ \text{神经元数})$$

## 六、一个算例

取一层：两个输入、一个神经元，$w=(0.6,\ -0.3)$，$\Lambda_{\max}=868$。

$$\rho_{1}=868\cdot\frac{0.6}{0.6}=868,\qquad \rho_{2}=868\cdot\frac{0.3}{0.6}=434$$

**正权重（上升阶梯）**：$\lambda_1(x)=\mathrm{round}(868x)$，即 $0,868,1736,\dots,13020$；
每步 $+868$，容器值 $V=15+868=\mathbf{883}\le897$ ✓（走反式接线）。

**负权重（下降阶梯）**：$\lambda_2(x)=\mathrm{round}((15-x)\cdot434)$，即 $6510,\ 6076,\dots,0$；
每步 $-434$，容器值 $V=15+434=\mathbf{449}\le897$ ✓。

$$\Lambda_1=\lambda_1(X_1)+\lambda_2(X_2),\qquad
Q_1=\Lambda_1-\bigl(\lambda_1(0)+\lambda_2(0)\bigr)=868X_1-434X_2$$

$$Q_{1,\min}=-6510,\qquad Q_{1,\max}=13020,\qquad
N_1=Q_1+6510\in[0,\ \mathbf{19530}]$$

三个端点可以手验：

| 输入 | $X_1$ | $X_2$ | $\Lambda_1$ | $Q_1$ | $N_1$ |
|---|---:|---:|---:|---:|---:|
| $x=(-,\ \text{最小})$ | 0 | 15 | 0 | $-6510$ | **0** |
| 两端都最小 | 0 | 0 | 6510 | 0 | 6510 |
| 两端都最大 | 15 | 15 | 19530 | 6510 | 13020 |
| $x=(\text{最大},\ \text{最小})$ | 15 | 0 | 13020 | 13020 | **19530**（上界） |

> 注意第一行 $\Lambda_1=0$ 但 $N_1=0$、第二行 $\Lambda_1=6510$ 而 $N_1=6510$——
> 这正是折叠的作用：把那个 6510 的常数**精确地**移出去，剩下的才是要量化的量。

## 判据与反例

1. **别把本页算法套到数模结合上。** 那边一位一个容器、输入有 $b$ 位；这边一条 16 项阶梯、输入只有 16 级。
2. **别把 $\mathrm{round}(x\rho)$ 写成 $x\cdot\mathrm{round}(\rho)$。** 后者累积误差最坏 7.5，前者处处被 0.5 咬住。
3. **别让所有坐标共用一个 $\rho$。** 相对误差 $\approx1/(2\rho_i)$ 逐坐标独立，只有把最大那一路顶满才整体最优。
4. **$\lambda$ 恒为非负。** 比较器不能输出负信号；靠“正权重上升、负权重下降 + 对齐到零”实现，不能靠偏移硬撑。
5. **不折叠就白量化了。** 常数项可达数万，步长按整个量程定，分辨率被吃掉；折叠后才回到 $0.0035$ 量级。
6. **$N_j$ 的上界是 $\sum 15\rho$，不是 $16\times$某值。** 它决定后面步长与是否需要环。
7. **868 是两种截断的交集**，不是随便定的阈值；只用一种截断时可以放宽到 882，但布线通常两种都有。
