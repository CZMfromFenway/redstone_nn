## 十条结论（先记这十条，其余可查）

1. **二期的验收标准不是准确率，是乘法数 + 盲测。** 最终灰度 2,304 乘法，是 512 logits 教师（202,240）的 **1/88**，三轮盲测测不出差异。
2. **生成不是收缩。** 分类是 225→10 一次聚合；生成是 64 个像素各要一条聚合通路。输出通道数、输入维数、隐层宽度**全部直接是成本**。
3. **镜像布局免费减半。** 32 个自由位置；规范集上左右两半逐位置相等 99.32%（灰度）/ 98.69%（彩色）。
4. **PCA 条件赢，但赢在"能调平滑度"而不是"能指定这张脸"。** PCA-4 的 acc 只有 0.4041，可它画的脸更干净——低维丢掉的高频主成分正是杂色来源。
5. **输出 512→32 的代价是数学上限，不是调参问题。** 28.14% 的位置条件分布多峰，连续标量只能取均值；实测只有 26%~29% 的输出落在整数级 ±0.1。
6. **后处理 min-max 是白捡的 41 点良率**（20.9%→62.1%，p=1.1e-9）；把它烘焙进训练反而更差（30.3%，p=4.8e-3）。
7. **筛选是弱杠杆。** 对种子打分只值 3~5 点，因为种子与生成脸的相关系数只有 0.53~0.67（$r^2\approx0.3$）。真正的杠杆是采样分布：矩形夹取把良率从 66.5% 提到 89.1%，代价是只留 23.4% 的空间。
8. **彩色线唯一确定的收益是"离散化"。** 连续 RGB 32.8% → 8 色索引 50.0%；K 从 8 加到 32 多花 96% 乘法，良率差 p=0.175 不显著，脸反而更软。
9. **训练后吸附 ≫ 事前约束。** 同一批权重只换调色板（吸附到真实 MC 色）→ 57.3%；把调色板事前锁死重训 → 33.6%（p=0.0008）。
10. **指标会骗人，二期栽了三次**（循环评估 100%、C1 自评 95.1% 实测 41.0%、C2 边缘 +19% 实测 43.2%），另有两次**度量本身有 bug**（数据行序错开、同色率恒真）。任何"被模型直接优化的量"都不能当评价指标。

## 四期（彩色头像）要继承什么

四期是彩色线，所以二期的**彩色部分**是直接接口，灰度部分主要提供成本口径与方法论。

### 直接继承（已复验）

| 资产 | 内容 | 出处 |
|---|---|---|
| **输入设计** | 8 个独立标准正态 N(0,1) 截断 ±3.5。理由是颜色 PCA 前 8 维协方差几乎就是单位阵：特征值 0.982~1.015、条件数 1.033、平均非对角相关 0.0029 | 02 §C1、03 §V4 |
| **输出编码** | 每像素 K 路 argmax + 调色板查表，K=8 → **3 bit/像素**、全脸 96 bit、50,176 乘法 | 02 §C2 |
| **真实色来源** | **在成品上吸附**，不要在训练目标里锁调色板（吸附不掉分，事前约束掉 23.7 点） | 02 §C3 |
| **布局** | 32 个自由位置、列优先、行内镜像（彩色镜像一致率 98.69%） | 02 §C1 |
| **成本口径** | 乘法数 = $\sum n_{\rm in}n_{\rm out}$；灰度 2,304 + 打分器 14；彩色 50,176 | 02 一览表 |

### 谨慎继承（方法可借，结论不可搬）

- **"旋钮 + 采样分布"的输入哲学**：灰度用 4 维 PCA、彩色用 8 维颜色 PCA；四期若用 diffusion 潜变量，仍需给出"潜变量的自然分布是什么、能不能零成本采样"这一答案。
- **矩形夹取 / 风格高斯的采样限幅**：它比筛选有效得多，且成本为零（随机源限幅）。四期若允许多步采样，限幅点会更多。
- **后处理量化的思路**：二期的 min-max 拉伸是"零成本改观感"的样板；四期彩色若走调色板路线，量化本身就是编码。

### 不要继承（已被证伪）

- **两阶段（先灰度再上色）**：生成时会炸成荧光色。
- **C1 结构损失、C2 对抗**：两次都是"指标漂亮、人看着更差"，且根因都是"判别器在 8×8 上平凡可分"。
- **对种子打分的筛选**：上限由种子与输出的相关性锁死（$r^2\approx0.3$）。
- **用同色率 / 代理打分器的绝对值做验收**：前者有 bug（下限 0.5），后者把 32.8% 报成 67.1%。

### 四期已知的直接线索（二期留下的）

1. **输入维数几乎免费**：8 → 12/16 只加 1.0%/2.0% 乘法，因为乘法大头在最后一层（$32\times K$）。而 8 个颜色分量丢掉了 25% 的方差。
2. **4 bit/通道可能不够**：量化下限 0.205 级是**平均**误差，纯红/纯白在 16 级下只有 16 个取值。
3. **彩色脸的良率只有两个真实数据点**：round 11 的 57.3%（n=103）与 round 12 的 61.1%（n=108），合并 59.2%（125/211）。四期任何"更好"的彩色模型都必须与这条基线同轮对照。
4. **彩色累计标签 1,108 条**（round 6/8/11/12），都在 `results/preference/labels.jsonl` 里，可直接复用为四期的对照基线。

### 本目录不覆盖的边界

- **没有红石成本换算**：本页只给乘法数。乘法数怎么变成容器、环数、体积，在 `20_数学`；而"编译成 schem"的整条链路（`40_编译`）目前没写，所以四期暂时只能用乘法数当成本代理。二期留下的实测只有一处可比：2,304 乘法 + 14 乘法打分器的灰度装置当时被判定"可移植"。
- **没有分辨率研究**：二期全部在 8×8 单面上做。分辨率翻倍对"每像素一条通路"的成本是平方级的，二期没测过。
- **没有 diffusion / 多步采样**：二期的生成器都是**单步前馈**。四期若走 diffusion，本文的"一次前向 = 一次生成"成本模型不成立，需要另立口径。
- **图里的脸不是"最好看的"脸**：每张图展示的是**该模型在某个开关下随机抽取一批**的分布，不是精选。这是二期自己的规矩（"逐模型随机，不对比单张"），也便于判断模型的真实下限。
