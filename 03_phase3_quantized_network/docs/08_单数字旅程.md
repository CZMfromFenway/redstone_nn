# 一个数字的旅程：PC0 → 隐单元 46 → 像素 3

**阶段**：P0
**日期**：2026-10-20
**脚本**：`src/trace_one.py`

---

## 〇、先把两个前提说准

### 使用的模型

`webapp/pca22_dim4w64L1_model.json`

| 项 | 值 |
|---|---|
| 结构 | **4-64-32**，单隐层 |
| 乘法 | 2,304 |
| 层 0 | `Linear(4→64)`，后接 ReLU |
| 层 1 | `Linear(64→32)`，**无 ReLU** |
| `mode` / `output_mode` | `gray32` / `continuous32` |
| `post` | `stretch` |
| 输入 | 4 个原始 PCA 系数，**无标准化**（meta 里没有 zmean/zsd） |
| 输入域 | $[-3.5,\ 3.5]$，来自 $N(0,1)$ 截断 |

与二期 `src/mc_grey.py` 的加载方式逐项核对一致：`Linear → ReLU → Linear`，最后一层不加激活。

### 配色方案

**16 级灰度**，即 `clip[0,15] → 逐张 min-max 拉伸 → np.rint`。

**不是 MC 11 档。** 11 档是在这之后再套一张归并 LUT（`webapp/merge_mc11.json`），**它在网络之后、只改变最终映射**，不影响本文件里的任何网络侧数字。两种配色的差别只在最后一步：16 级的分母是 15，11 档的分母是 10。

## 一、这一张脸

取固定种子 `rng(11)` 的第一个样本：

| | PC0 | PC1 | PC2 | PC3 |
|---|---:|---:|---:|---:|
| 原始采样 | +0.03419 | +1.35975 | +1.22472 | −0.51031 |
| $X$（$b=8$） | 129 | 177 | 172 | 109 |
| 格心重建 $x$ | +0.04102 | +1.35352 | +1.21680 | −0.50586 |
| 二进制 | 10000001 | 10110001 | 10101100 | 01101101 |

浮点路吃格心重建值，所以两条路**输入完全相同**。

**这一张脸上 64 个隐单元中 50 个激活、14 个被 ReLU 截断。**

---

## 二、选定的通路

在**这一张脸上实际激活**的隐单元里，取 $\lvert w[:,0]\rvert$ 最大的那一路，即 PC0 真正把影响传了下去的那一支：

$$\text{PC0}\ \longrightarrow\ \text{隐单元 }46\ \longrightarrow\ \text{像素 }3\ (row\ 3,\ col\ 0)$$

---

## 三、层 1：隐单元 46

$$y_{46}=\mathrm{relu}\left(w_{46}^\top x+\theta_{46}\right)$$

| $i$ | 输入 | $x_i$ | $w_{46,i}$ | $w\cdot x_i$ | $X_i$ | 位权重 $W^{(k)},\ k=0\dots7$ |
|---:|---|---:|---:|---:|---:|---|
| 0 | **PC0** | +0.04102 | **+0.881974** | **+0.036175** | **129** | +14 +28 +55 +110 +220 +441 +882 **+1764** |
| 1 | PC1 | +1.35352 | +0.381398 | +0.516228 | 177 | +6 +12 +24 +48 +95 +191 +381 +763 |
| 2 | PC2 | +1.21680 | +0.113290 | +0.137851 | 172 | +2 +4 +7 +14 +28 +57 +113 +227 |
| 3 | PC3 | −0.50586 | −0.193077 | +0.097670 | 109 | −3 −6 −12 −24 −48 −97 −193 −386 |
| | | | $\theta=$ **+0.46598** | | | |

**注意 PC0 那一行：位权重严格按 $2^k$ 等比，最高位 +1764 已越过 882**（这正是备选方案允许的那一位），次高位 +882 恰好顶到单容器上限。

### 连续

$$z_{46}=+0.036175+0.516228+0.137851+0.097670+0.46598=\mathbf{+1.253901}$$

$$y_{46}=\mathrm{relu}(z_{46})=\mathbf{+1.253901}\quad(\text{正值，未被截断})$$

### 整数

PC0 的 $X_0=129=1000\,0001$，只有第 0 位和第 7 位为 1：

$$W_0^{(0)}X_0^{(0)}+W_0^{(7)}X_0^{(7)}=(+14)\cdot1+(+1764)\cdot1=+1778$$

四个输入全部累加：

$$F'=2809,\qquad F'_{\min}=-769,\qquad F=F'-F'_{\min}=\mathbf{3578}$$

$$C_0=-3.660387,\quad F_a=2860.712,\quad c_1=14,\quad \text{每级}=0.024499$$

$$\bar F=F-F_a=717.288\quad\Longrightarrow\quad Y_{46}=\left\lfloor\frac{717.288}{14}\right\rfloor=\mathbf{51}$$

### 对照

| | 连续 | 整数 |
|---|---:|---:|
| $y_{46}$ | 1.253901 | 寄存器 51，解码 **1.249463** |
| 差 | — | **−0.004439**，即 **−0.181 级** |

## 四、层 2：像素 3

$$z_3=\sum_i w_{2,3i}\,y_{1,i}+\theta_{2,3}$$

这一路从隐单元 46 取到的权重是 $w_{2,3,46}=+0.873706$（64 个权重里绝对值最大的一个，0.000702 到 0.873706）。

| | 连续 | 整数 |
|---|---:|---:|
| 来自隐单元 46 的贡献 | $+0.873706\times1.253901=+1.095541$ | 位和 **+369** |
| 其余 63 项合计 | +8.166179 | +2733 |
| $\theta_{2,3}$ | +0.046991 | 并入 $C_0$ |
| **输出** | $z_3=\mathbf{+9.308711}$ | $F=16269$，$c_2=20$，$Y_3=\mathbf{156}$ |

整数路里 $Y_{46}=51=0011\,0011$，逐位与它的位权重相乘：

| $k$ | 0 | 1 | 2 | 3 | 4 | 5 | 6 | 7 |
|---|---:|---:|---:|---:|---:|---:|---:|---:|
| 位权重 | +7 | +14 | +29 | +58 | +116 | +232 | +464 | +928 |
| $Y_{46}^{(k)}$ | 1 | 1 | 0 | 0 | 1 | 1 | 0 | 0 |
| 贡献 | +7 | +14 | 0 | 0 | +116 | +232 | 0 | 0 |

$$\text{小计}=+369$$

层 2 的量化：每级 $c_2/\text{scale}=0.059078$，解码 $z_3=156\times0.059078=\mathbf{+9.216151}$。

## 五、完整旅程

| 步骤 | 连续 | 整数 |
|---|---:|---:|
| 1. PC0 采样值 | +0.03419 | — |
| 2. PC0 量化成 $X_0$ | — | 129 |
| 3. PC0 重建值 $x_0$ | +0.04102 | 10000001 |
| 4. 给隐单元 46 的贡献 | +0.036175 | 位和 +1778 |
| 5. 隐单元 46 输出 $y$ | +1.253901 | **51** |
| 6. 给像素 3 的贡献 | +1.095541 | 位和 +369 |
| 7. 像素 3 输出 $z$ | +9.308711 | +9.216151 |
| 8. 这张脸拉伸前极值 | 5.0308 ~ 13.1185 | 4.9811 ~ 13.0135 |
| 9. 像素 3 的 16 级值 | **8** / 15 | **8** / 15 |

$$\text{PC0 走完全程，最终没有改变像素 3 的灰度级}$$

**第 4、6 行的整数列是位权重的相加量（$\bar F$ 空间的单位），连续列是物理量（$z$ 空间）。二者差一个缩放与常数，不可直接相比。可比的是第 5、7、9 行。**

## 六、PC0 在这条路上的话语权

| 环节 | 数值 | 占比 |
|---|---:|---:|
| PC0 在隐单元 46 的加权和中 | 0.036175 / 0.787924 | **4.6%** |
| 隐单元 46 在像素 3 的加权和中 | 1.095541 / 9.308711 | **11.8%** |
| **整条通路** | | $4.6\%\times11.8\%=\mathbf{0.54\%}$ |

**这一张脸上 PC0 的采样值只有 +0.034，本来就接近均值，所以它的话语权小。** 这不是选路的偏差，而是这个数字本身在这一张脸上就没什么作用。

若想看 PC0 主导的情形，把种子或 PC 换成另一个即可，脚本对任意 $(\text{face}, \text{PC}, j, p)$ 都能重跑。

## 七、顺带得到的红石数字

| 部件 | 累加器必须容下的范围 |
|---|---|
| 隐单元 46 | $F\in[2860,\ 6254]$ |
| 像素 3 | $F\in[13137,\ 18215]$ |

$$\text{两者都远在强模上限 } 2^{31}-1=2{,}147{,}483{,}647 \text{ 之内}\quad\Longrightarrow\quad\text{每神经元一个累加器，不分段}$$

---

## 八、这一路实例给出的三个等式

$$\text{一件乘法}\ =\ b\ \text{条二值扇入}\qquad
\text{位权重}\ \propto 2^{k}\qquad
\text{输出}\ =\ \left\lfloor \frac{F-F_a}{c}\right\rfloor$$

其中第三条里的 $F_a$ 与 $c$ 都是编译期常数，只依赖量化后的位权重，不依赖运行时的输入。
