## 一、LAHC 的全称

$$\textbf{L}\text{ate}\ \textbf{A}\text{cceptance}\ \textbf{H}\text{ill }\textbf{C}\text{limbing}$$

**延迟接受爬山法**。Burke & Bykov 提出（2008 年初版，2017 年完整分析）。

逐词解释：

| 词 | 含义 |
|---|---|
| **Hill Climbing** | 只做单点移动的局部搜索，不像遗传算法那样有种群 |
| **Acceptance** | 关键在于"接受什么"——普通爬山只接受更好的 |
| **Late** | 判断标准不是"现在"，而是"$L$ 步之前" |

$$\text{接受条件：}\quad J_{\text{候选}}\le H[i\bmod L]\quad\textbf{或}\quad J_{\text{候选}}<J_{\text{当前}}$$

$H$ 是长度 $L$ 的环形历史数组，每接受一次就把当前值写进 $H[i\bmod L]$。

**"Late"体现在**：候选解要跟 $L$ 步**之前**的记录比，不是跟现在比。所以早期 $H$ 里全是差值，什么移动都接受；后期被好值填满，自动收紧成爬山。**容忍度自己衰减，不需要温度表。**

## 二、$J$ 的精确定义

### 2.1 目标 CDF $F^*$

从该风格的 **被接受样本**（$\lvert x\rvert\le3.5$）里统计第 $i$ 个通道的 $X_i$ 直方图：

$$p^*(x)=\frac{\#\{\text{样本 }s: X_i(s)=x\}}{N_{\text{样本}}},
\qquad x=0,\dots,255$$

$$F^*(x)=\sum_{y=0}^{x}p^*(y)$$

### 2.2 模型 CDF $\hat F$

**第一步**：$M$ 次卷积得和的分布

$$q(s)=\Pr\Bigl[\sum_{k=1}^{M}w_kv_k=s\Bigr],\qquad s=0,\dots,2\sum_k w_k$$

**第二步**：平移 $c$ 并截断

$$\hat p(x)=\sum_{\substack{s\\ \mathrm{clip}(c+s,\,0,\,255)=x}}q(s)$$

即每个原子移到 $x=c+s$，掉到 0 以下的并到 0，超过 255 的并到 255。

**第三步**：累积

$$\hat F(x)=\sum_{y=0}^{x}\hat p(y)$$

### 2.3 目标函数

$$\boxed{\ J=\max_{x\in\{0,\dots,255\}}\bigl\lvert\hat F(x)-F^*(x)\bigr\rvert\ }$$

$$J\in[0,1],\qquad J=0\iff\text{两个分布完全相同}$$

### 2.4 怎么读这个数

$J$ 是**Kolmogorov–Smirnov 统计量**。它的意思：

$$\text{取任意阈值 }x\text{，模型说"有 }\hat F(x)\text{ 比例的样本}\le x\text{"，真值是 }F^*(x)\text{。}$$
$$J=\text{这个差在所有阈值上的最坏值。}$$

**等价说法**：$J$ 是"用模型分布当真实分布时，任何分位数最多错多少质量"。

$J=0.008$ 意味着：**在任何亮度阈值上，累计概率最多差 0.8%。**

### 2.5 为什么取最大值而不取平方和

| 候选 | 问题 |
|---|---|
| $\sum_x(\hat F-F^*)^2$ | 会被 256 个点平均掉，某处差 0.05 但别处都好时惩罚不够 |
| $\max_x\lvert\hat F-F^*\rvert$ | **直接就是最坏情况**，且等于 KS 距离 |
| $\sum_x\lvert\hat p-p^*\rvert$（TV） | 被格点振荡主导，见下 |

## 三、初值是怎么构造的

### 3.1 目标：让前两个矩都对上

模型的两个矩：

$$E[X]=c+\sum_{k=1}^{M}w_kE[v_k],
\qquad
\mathrm{Var}(X)=\sum_{k=1}^{M}w_k^2\,\mathrm{Var}(v_k)$$

（方差那一行用到**投掷器互相独立**，交叉项为零。）

**如果均值错了**，整条分布平移，$J$ 立刻跳到 0.5 左右。**如果方差错了**，分布太窄或太宽，$J$ 也在 0.2 以上。所以初值必须把这两个矩钉住。

### 3.2 为什么选 $(4,1,4)$

对 $N=9$ 的所有三值形状算方差：

| 形状 | $E[v]$ | $\mathrm{Var}(v)$ |
|---|---:|---:|
| $(4,0,5)$ | 1.111 | **0.9877** ← 全局最大 |
| $(5,0,4)$ | 0.889 | **0.9877** ← 全局最大 |
| $(3,0,6)$ | 1.333 | 0.8889 |
| **$(4,1,4)$** | **1.000** | **0.8889** |
| $(6,0,3)$ | 0.667 | 0.8889 |
| $(5,1,3)$ | 0.778 | 0.8395 |

**注意：$(4,1,4)$ 不是全局方差最大。** 全局最大是 $(4,0,5)/(5,0,4)$ 的 0.9877。

选 $(4,1,4)$ 的三个理由：

**① 它是"$E[v]=1$"那一族里方差最大的**

$E[v]=1$ 要求 $b+2c=9$，配合 $a+b+c=9$ 得 $a=c$，只有五种：

| 形状 | $\mathrm{Var}(v)$ |
|---|---:|
| **$(4,1,4)$** | **0.8889** ← 最大 |
| $(3,3,3)$ | 0.6667 |
| $(2,5,2)$ | 0.4444 |
| $(1,7,1)$ | 0.2222 |
| $(0,9,0)$ | 0 |

$E[v]=1$ 的好处：$\sum_k w_kE[v_k]=\sum_k w_k$，于是 $c=m-\sum w_k$，**偏置公式最简**。

**② 它三个值都用上（$b=1\neq0$）**

$(4,0,5)$ 中间是空的，两点分布。$M$ 个两点分布之和落在稀疏得多的格点上。$(4,1,4)$ 有三根原子，$M$ 次卷积后格点更密。

**③ 对称（$a=c$）**

单个投掷器对 0 和 2 端不偏，所以初值不带人为偏态。偏态交给搜索去调。

### 3.3 为什么会用这个权重公式

固定"所有投掷器同形状 $(4,1,4)$、所有权重相同 $w$"，则

$$E[X]=c+Mw,\qquad \mathrm{Var}(X)=Mw^2\cdot\tfrac89=Mw^2\cdot0.8889$$

**要求 $\mathrm{Var}(X)=s^2$**（$s$ 是目标标准差），解出

$$\boxed{\ w=\sqrt{\frac{s^2}{0.8889\,M}}\ }$$

**要求 $E[X]=m$**（$m$ 是目标均值），解出

$$\boxed{\ c=\mathrm{round}\bigl(m-Mw\bigr)\ }$$

**两个方程、两个未知数，其余全是自由选择。** 这就是全部推导。

### 3.4 这个初值自动给出合适的支撑

和的支持是 $2Mw$。把 $w$ 的公式代进去：

$$2Mw=2M\sqrt{\frac{s^2}{0.8889M}}=2s\sqrt{\frac{M}{0.8889}}=2.12\,s\sqrt{M}$$

| $M$ | 支撑 | 覆盖 |
|---:|---:|---|
| 8 | $6.0s$ | $\pm3.0\sigma$ |
| **10** | $6.7s$ | **$\pm3.35\sigma$** |
| 12 | $7.3s$ | $\pm3.7\sigma$ |

$$\text{目标要 }\pm3.5\sigma\quad\Longrightarrow\quad M=10\text{ 时 }6.7s\text{ 恰好够，}M=8\text{ 略短}$$

**所以"方差对上"这件事自动就把"支撑够不够"也解决了**——这两个本来是一件事的两面。

### 3.5 初值到底有多好

实测 24 个通道的初值：

$$J_{\text{初}}\in[0.035,\ 0.21]$$

**只有 20%～50% 的准确度。** 也就是说：

$$\text{前两个矩对上后，剩下的残差全部来自}\textbf{偏度、峰度、格点}$$

而这正是搜索要做的事——**搜索贡献了约 90% 的精度**（初值 0.08 → 终值 0.008）。

## 四、把整个流程串起来

```
第 i 个通道的目标直方图 p*(x)          ← 从该风格被接受的样本里数出来
        │
        ├─ 算两矩：m = Σ x p*(x),  s² = Σ (x−m)² p*(x)
        │
        ├─ 初值：形状全 (4,1,4)
        │        w = round(√(s²/(0.8889·M)))
        │        c = round(m − M·w)
        │
        ├─ 评估 J = max_x |F̂(x) − F*(x)|
        │
        ├─ 循环 2500 次：
        │     随机挑一个投掷器
        │     一半概率改权重 ±1/±2，一半概率换形状
        │     重算 c（重新对齐均值）
        │     算 J，按 LAHC 规则决定接受与否
        │
        └─ 重启 2 次取最好 → (w_1..w_M, s_1..s_M, c)
```

**一句话：初值负责把"多大、多宽、在哪"定下来；搜索负责把"什么形状"改对。**
