## 二、搜索原理

### 2.1 要解的是什么

**目标**：某个输入通道上 $X\in\{0,\dots,255\}$ 的概率分布（从该风格被接受的样本里统计出的 256 个数）。

**模型**：$X=\mathrm{clip}\bigl(c+\sum_{k=1}^{M}w_kv_k\bigr)$，每个 $v_k$ 独立地取 $\{0,1,2\}$，概率 $(a_k,b_k,c_k)/9$。

### 2.2 为什么是卷积

$M$ 个投掷器**互相独立**，所以和的分布是各自分布的**卷积**：

$$p_X(x)=\sum_{\substack{v_1,\dots,v_M\\ c+\sum w_kv_k=x}}\ \prod_{k=1}^{M}p_k(v_k)$$

算法上就是**迭代卷积**：从 0 处的 δ 开始，每加一个投掷器，就把当前分布 $q$ 换成

$$q\ \longleftarrow\ q*(p_0\delta_0+p_1\delta_{w_k}+p_2\delta_{2w_k})$$

即把 $q$ 复制三份，分别平移 $0,w_k,2w_k$，按 $p$ 加权相加。$M=11$ 次之后得到和为 0 到 $2\sum w$ 上的完整分布。

### 2.3 自由度 vs 约束

| | 数目 |
|---|---:|
| 目标要拟合的概率值 | 256 个 |
| 自由整数（$M$ 个权重 + $M$ 个形状 + 1 个偏置） | $2M+1\approx21\sim33$ |

$$\text{严重超定}\quad\Longrightarrow\quad\text{残差不可能归零}$$

这就是为什么 CDF 差停在 0.015 附近——**不是搜索没做好，是这个形状族的表达能力到此为止。**

### 2.4 为什么用 CDF 而不是 TV

$$\mathrm{TV}=\tfrac12\sum_x\lvert p(x)-q(x)\rvert，
\qquad
\mathrm{CDF}=\sup_x\bigl\lvert F_p(x)-F_q(x)\bigr\rvert$$

投掷器之和落在由权重生成的**格点**上，点态概率会剧烈振荡。同一个拟合里：

$$\mathrm{CDF}=0.0100\quad\text{而}\quad\mathrm{TV}=0.0678$$

**TV 被格点振荡放大，CDF 不受影响。** 三个理由选 CDF：

1. **它直接控制分位数误差**：$\mathrm{CDF}\le\varepsilon$ 意味着任何分位数都落在目标对应位置的 $\varepsilon$ 质量之内。
2. **它在离散化下稳定**：格点怎么排不影响它。
3. **它对下游才重要**：人脸关心的是"某个输入区间出现多频繁"，不是"某一个 X 值出现多精确"。

### 2.5 为什么用离散局部搜索而不是梯度下降

目标函数是**整数变量的函数**。把某个权重改 1，所有原子整体平移 1——CDF 差会**跳变**。

$$\text{目标函数是分段常数}\quad\Longrightarrow\quad\text{没有梯度，连续优化不适用}$$

所以用离散局部搜索（(1+1) 爬山 + 多次重启）：

```
初值：形状全取 (4,1,4)（方差最大），权重等分到目标方差
      权重 w = round(√(Q/M))，其中 Q = σ²/0.8889
      偏置 c = round(m − Σ w_k·E[v_k])        ← 自动把均值对齐

重复：
    随机挑一个投掷器
    ├─ 一半概率：权重 ±1 或 ±2
    └─ 一半概率：形状换成 55 种里的随机一种
    重算偏置 c（把均值重新对齐）
    若 CDF 差变小，接受；否则丢弃

重启 3 次，取最好
```

**为什么改偏置而不是固定它**：均值必须精确落在目标均值上，否则整条曲线平移。把 $c$ 设成"使均值对齐的值"（$\pm1$ 微调），就把一个连续约束消掉了，搜索只需要管形状。

**为什么 M=14/16 反而更差**：维度越高，爬山越容易卡在局部极小。这是搜索的局限，不是模型的局限。

### 2.6 为什么放开形状能减半误差

形状固定为 $(4,1,4)$ 时，每个投掷器都是**同一个三点分布的缩放**，$M$ 个的和就是同一形状的 $M$ 次卷积——整个族每通道只有一个自由度（权重）。

放开形状后，每个投掷器多两个自由度（$a+b+c=9$，两个自由），分别控制：

$$E[v]=\frac{b+2c}{9}\quad(\text{质量落在 0 和 2 之间的哪里}),
\qquad
\mathrm{Var}(v)=\frac{b+4c}{9}-E[v]^2\quad(\text{多散})$$

搜索实际选出的形状呈现明显的两极分化：

| 形状 | $p$ | 出现次数 | 性质 |
|---|---|---:|---|
| $(3,0,6)$ | 0.33, 0, 0.67 | 15 | 两点，偏上 |
| $(3,1,5)$ | 0.33, 0.11, 0.56 | 15 | 偏上 |
| $(7,0,2)$ | 0.78, 0, 0.22 | 13 | 两点，偏下 |
| $(3,3,3)$ | 1/3, 1/3, 1/3 | 12 | 均匀，最平滑 |
| $(2,0,7)$ | 0.22, 0, 0.78 | 12 | 两点，强烈偏上 |
| $(4,1,4)$ | 0.44, 0.11, 0.44 | 11 | 方差最大 |

$$\boxed{\text{机制：混合「窄分量」与「宽分量」}}$$

**纯卷积只能生成单一形状的和；混合不同形状相当于在多个尺度上叠加，才能拟合非纯高斯的边缘分布（这些风格被立方体裁过，形状本来就偏）。**

### 2.7 还受什么限制

| 限制 | 影响 |
|---|---|
| 支撑有界 | $M=10$ 时铺到 $\pm3.35\sigma$，够；$M<8$ 就不够 |
| 格点稀疏 | 点态概率振荡，但 CDF 与下游都不受影响 |
| 只有 55 种形状 | 若允许不满 9 格（$1/7$、$1/5$ 等分母），族会更大 |
| 爬山会卡 | $M\ge14$ 时维度太高，搜索质量下降 |
