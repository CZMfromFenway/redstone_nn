## D. 仍然可用的规则、公式与流程

### D1 符号与量化约定

- **量化通式**：`Q(v) = ⌊(v−v_min)/(v_max−v_min)·2^b⌋`，结果 **clamp 到 [0, 2^b−1]**。条件：无条件适用；`t=1` 时通式给出 `2^b`（越界），必须靠 clamp 或改尺度为 `2^b−1`；本项目选 clamp，理由是保持 2^b 个等宽格、避免整数除法。出处：docs/03:27-31, 03:161-174, 03:182。
- **偏移必要性判据**：`v_min ≠ 0` 才需要偏移项。哪些变量恒有 `v_min=0`：**任何 ReLU 层的输出，以及以它为输入的下一层的 x**；哪些需要偏移：第一层输入（旋钮跨 0）、无 ReLU 的输出层。反向判据也成立——一个无 ReLU 的输出层会重新引入偏移需求。出处：docs/03:62-71, 03:184-185。
- **解码约定**：默认**格心** `v̂ = v_min + (Q+½)/2^b·(v_max−v_min)`。条件：层内有 ReLU 时必须格心——实测格心比格边好约 5 倍，且该比值不随 b 变；原因见下条。出处：docs/03:130-155。
- **ReLU 零值原子的定量后果**：ReLU 层 23.35% 的输出恰为 0，格心让这些 0 抬半步，使该层平均绝对误差比同跨度连续变量高约 50%（8.492/256 半步 0.01659，加权 `0.2335×0.01659+0.7665×0.00829=0.01023`）。条件：只在含 ReLU 的层出现；这一偏置是常数，可并入下一层偏置，实测只再改善 1%，**不值得单独加一路常数**。出处：docs/03:111-119, 03:155。
- **位分解权重约定（39 号采用的方案）**：`W_i^(j)` 是**独立整数**、与 `2^j` 成正比，**不是二进制位**；`X_i = Σ_j X_i^(j) 2^j`；`F' = Σ_j Σ_i W_i^(j) X_i^(j)`；`F = F' − F'_min`，`F'_min = Σ min(0, W)`。条件：`F'_min` 只依赖权重表，是编译期常数；减它是为了给激活/比较器只吃非负信号。出处：docs/03:195-213。
- **符号体系以 docs/14 为准**（32 号明确认定）：小写/希腊=实数，大写=整数，上标=位号（k=b−1 为高位），下标序=（输出，输入），hat=量化后逆回。`α_j` 逐通道缩放、`β` 整层缩放、`δ_j` 通道实数分辨率；整数侧 `X/U/H/F/Y/A/c/V/G/B/Z/ΔZ/L`。出处：docs/14:9-54；docs/32:26-35。
- **两套符号的映射表（四期直接可用）**：手写版 `α_j/β/δ_j/U^(k)/V^(k)/H_j/G_p/F_j/G_p−G_p,min/A_j/B_p/c_j/15β` ↔ 编译器版 `σ/σ_i/δ_j/W^(k)_i,j/C_i/C_i,min/N_i/P_i/c_i/T_i`。出处：docs/32:39-51。
- **三处必须注意的符号冲突（不可擅自统一）**：
  - `F` 在 docs/03、05、06、12 中表示"抬正后的累加量（两层通用）"，在 docs/14 中只表示**层1**的非负累加（层2 改用 `G`），在 docs/13 中则被明确"让给用户"（自己用 `P`）。出处：docs/12:13-18；docs/13:207；docs/14:32-33。
  - `c` 三义：docs/03:252 的 `c = (x_max−x_min)/2^b` 是**输入步长**；docs/04-10 的 `c` 是**输出步长**（每级 F 数）；docs/14 里 `c_j` 又是层1 输出步长。docs/16 干脆把步长改名 `s_i`。出处：docs/03:252；docs/10:16；docs/16:74。
  - `A` 的下标集合不同：docs/12 的 `A_p` 是**两层通用**的 `z=0` 锚点；docs/14 把层1 叫 `A_j`（ReLU 阈值）、层2 叫 `B_p`（只是零点、不是阈值）。语义必须分开。出处：docs/12:30-36；docs/14:34,39-40。

### D2 编译七步与三开关

- **七步流程（手写定稿，逐条校核过）**：0 模型 → 1 输入量化（引入 Δ）→ 2 层1 位权重与累加（引入 α_j，`U^(k)=round(α_j u Δ/2^b 2^k)`，`H_j`，`F_j=H_j−H_j,min`）→ 3 整数 RELU（引入 A_j、c_j，`Y_j=clip(⌊(F_j−A_j)/c_j⌋,0,2^b−1)`）→ 4 层2 位权重（引入 δ_j、β，`V^(k)=round(β v δ_j 2^k)`，`G_p`）→ 5 层2 输出（引入 B_p，`Z_p=CLIP(G_p−G_p,min−B_p,0,15β)`）→ 6 归一化（`ΔZ`、`L_p`）→ 7 查表。条件：两层 MLP + 隐层 ReLU + 线性输出 + 有界输入。出处：docs/15:19-28；docs/32:53-64。
- **四通则**：①缩放不是自由参数，由 882 唯一反解；②全局还是逐通道由"要不要互相比"决定（层1 逐通道、层2 必须全局）；③零点逐通道且统一定义为"预激活=0 处的累加器读数"；④符号只出现在权重与 H/G 族，`CLIP` 的下界由比较器减法模式自带截断实现。出处：docs/15:34-71。
- **泛化到任意层（三开关）**：A = 输入跨度是否一致（→ δ 是标量还是向量）；B = 输出是否要求可比（→ σ 是标量还是逐通道）；C = 输出形式 ReLU 还是 CLIP（→ 有步长 s_i 还是只有宽度 W）。本项目两层恰好覆盖六种组合中的两种：(一致, 不要求, ReLU) 与 (不一致, 要求, CLIP)。出处：docs/16:25-33, 16:104-122。
- **每层编译五步（可直接实现）**：
  1. `σ_i = w_ref / (max_j |w_i,j|·δ_j·2^{b−2})`；B 要求可比时把 max 取到全部 (i,j)。
  2. `W^(k)_i,j = round(σ w_i,j δ_j 2^k)`，约束 `|W^(k)| ≤ 882 (k<b−1)`；`C_i = Σ_k Σ_j W^(k) A^(k)_j`，`C_i,min = Σ min(0,W)`。
  3. `P_i = round(−σ_i κ_i − C_i,min)`，其中 `κ_i = θ_i + Σ_j w_i,j(a_j^0 + ½δ_j)`。
  4. ReLU 层：`B_i = clip(⌊((C_i−C_i,min)−P_i)/s_i⌋, 0, 2^b−1)`，`s_i = ⌈(C_i^max−C_i,min−P_i)/(2^b−1)⌉`；CLIP 层：`B_i = CLIP(C_i−C_i,min−P_i, 0, W)`，`W = round(Λσ)`（本项目 Λ=15）。
  5. `δ^(out)_i = s_i/σ_i`（ReLU）或 `1/σ_i`（CLIP）。
  出处：docs/16:36-87。
- **w_ref 参数化与断言**：`σ = w_ref / (max|w|·δ·2^{b−2})` ⟹ `|W^(b−2)| = w_ref`、`|W^(b−1)| = 2 w_ref`。两个可用档：`w_ref=882`（最高位 1764，需许可"最高位可超 882"）与 `w_ref=441`（最高 882，全部位在单容器内）。编译器接口 `compile_network(layers, xmin, xmax, in_bits, w_ref=882)`，断言：非最高位 ≤882、最高位 ≤2³¹−1。出处：docs/16:161-189。
- **回归测试判据**：编译器与手算公式在 11 个量 × 2 种 w_ref 上**最大差全为 0**——任何改动后用 `src/verify_compiler.py` 重跑，差不为 0 即编译器被改坏。出处：docs/16:193-211；docs/32:88-94。
- **复用判据**：三层以上按层填开关表，ReLU 层的 `δ^(out)` 交给下一层；输出层是分类则把 CLIP 换成"取最大者"、LUT 换类别表；隐层非 ReLU 则 `P_i` 定义不变（仍是 c_i=0 处）、第 4 步换成该激活的单调整数版；输入未归一化则开关 A 设为"不一致"。出处：docs/16:137-145。
- **本项目两层的开关取值（可直接照抄）**：层1 = (A 一致, B 不要求, C ReLU)，σ=α_j∈[327,2697]，P=A_j∈[1524,6531]，c_j∈[10,33]，输出 b=8；层2 = (A 不一致, B 要求, C CLIP)，σ=β=242.744，P=B_p∈[5279,12142]，W=15β=3641，输出 12 位。出处：docs/16:104-120。

### D3 容器信号与可达性

- **信号公式**：`signal = 0 (U=0)`；`signal = 1+⌊14U/(64n)⌋ (U>0)`，其中 `U = 64·n_不可堆叠 + 4·n_16堆叠 + 1·n_可堆叠`，n 为容器格数。条件：一格装满可堆叠物品记 64 单位；不可堆叠物品每格只能 1 个但记 64 单位。实测核对：一期 512 个 setblock 文件 **0 个不符**。出处：docs/25:57-63；docs/26:19,172。
- **三种容器换算表**：木桶 n=27（满格 U=1728，极限 U=110,592）、漏斗 n=5（320 / 20,480）、投掷器 n=9（576 / 36,864）；三者极限信号都是 **897**，因为公式里 U 与 n 同时缩放；差别只在可达稠密度。出处：docs/26:21-27。
- **可达性判据（决定用哪种容器）**：木桶 898/898 全通；投掷器缺 96 个、首个缺口 804；漏斗缺 108 个、首个缺口 730。若用漏斗且需要 w_ref 接近 897，必须放弃高段。出处：docs/26:37-39,45-49。
- **897 与 882 的分工（必须区分口径）**：位权重**直接当容器内容**时上限 **897**；位权重**当 LUT 的阶跃量**时上限 **882**（因为 `Δλ = 15−b`，`b∈[0,897]` ⟹ `Δλ∈[−882,15]`）。这条区分在符号处理定下来之前不能合并。出处：docs/27:56-58；docs/25:36-38。
- **调色板**：`0..897` 共 **898** 个 setblock 文件，每个用 ≤27 格；生成 865..896 段时若固定取"最小 fill"会多占一格越界，正确做法是在可行 fill 区间里搜 `(A,R)` 使 `⌈A/64⌉+[R>0] ≤ 27`。放置函数只需坐标 + `run function vessel:barrel_N`。出处：docs/25:76-93, 25:97-124。
- **容器数账**：灰度模型 b=8 时 U 2,048 + V 16,384 + 偏置类 160 + 全局 2 ≈ 18,594 个容器；量级是一期（2,340）的 8 倍。出处：docs/25:182-190；docs/32:100-104。

### D4 投掷器采样与物理约束

- **采样模型**：`X = clip(c + Σ_{k=1..M} w_k v_k, 0, 255)`，每个 `v_k ∈ {0,1,2}`，形状 `(a_k,b_k,c_k)/9`，`a+b+c=9`。条件：各投掷器互相独立（所以和是卷积）。出处：docs/22:35；docs/23:31-39。
- **目标函数**：`J = max_{x∈[0,255]} |F̂(x) − F*(x)|`（KS 距离），不是 TV。判据：J 小 ⟺ 任何分位数最多错 J 的质量；投掷器之和落在稀疏格点上，TV 被格点振荡主导（同一拟合 CDF=0.0100 而 TV=0.0678）。出处：docs/24:59-80；docs/22:60-74。
- **偏置解析定（最重要的一步）**：`c = round(m − Σ_k w_k E[v_k])`。条件：均值错位是压倒性误差源（整条分布平移 1，J 立刻跳到 0.5 量级）；这一招把初始误差从约 0.5 压到约 0.08。出处：docs/23:59-69；docs/24:96, 24:149。
- **初值构造**：形状全取 `(4,1,4)`；`w = round(√(s²/(0.8889·M)))`；`c = round(m − M·w)`。条件：只用目标分布的前两矩（m, s²）；实测初值 J∈[0.035, 0.21]，即搜索贡献约 90% 的精度。出处：docs/24:139-179。
- **为什么必须 (4,1,4)**：`(4,1,4)` 不是全局方差最大（最大是 `(4,0,5)/(5,0,4)` 的 0.9877），但它是 **E[v]=1 那一族里方差最大的**（0.8889），而 E[v]=1 使偏置公式最简；且三点都用到、格点更稠。出处：docs/24:98-135。
- **LAHC 接受规则**：`J_cand ≤ H[i mod L]` **或** `J_cand < J_cur`，`L=80`；每接受一次把当前值写进 `H[i mod L]`。条件：目标函数是整数变量的分段常数函数（改一个权重会让整块原子平移），无梯度；实测同为 7501 次评估，爬山只接受 28 次（0.4%）终值 0.0183，LAHC 接受 861 次（11.5%）终值 0.0137。出处：docs/23:92-104；docs/24:22-26。
- **搜索配置（可复现）**：每通道 M=10；权重整数 1..31；形状 55 种 (a,b,c) 且 a+b+c=9；单坐标移动（1/2 概率改权重 ±1/±2，1/2 概率换形状）；每步重算 c；重启 2 次取最好；每次 2500 次循环。出处：docs/23:33-40, 23:84-88, 23:121；docs/24:196-202。
- **物理合法性（决定 M 个投掷器能不能真造出来）**：`U = 64a + 4B + C`，`B ∈ [b, 16b]`，`C ∈ [c, 64c]`，**a 没有自由度**（不可堆叠物品每槽恰好 1 个，不能超叠）。判定式 `7U mod 288 ∈ [7,27]`，等价于三条差分：`f(U)−f(U−64)=2`（不可堆叠喷出 → 信号 −2）、`f(U)−f(U−4)=1`（16 堆叠 → −1）、`f(U)−f(U−1)=0`（可堆叠 → 0），其中 `f(U)=⌊14U/576⌋`。出处：docs/27:64-80。
- **形状可用性**：`a,b,c ≥ 1` 的 **28 种形状全部有解**；可行 U 落在间距 `288/7≈41.14` 的格上（84, 125, 166, 207, 248, 289, 331, 413, 454…），所以"形状可任选，只要把 C 调到对应格上"。条件：每槽 1 个且不超堆叠是必要条件；只有每槽 1 个时可用形状仅 4/55。出处：docs/27:82-125；docs/26:96。
- **采样复用规则（两说冲突，须实测）**：docs/26:105 说"每喷出一个 U 就下降，喷出后读信号差只能可靠用一次，连续采样必须先 setblock 复位"；docs/27:138 反驳说"投掷器接空漏斗，喷出的物品会回去，不需要复位"。27 是后文，但**未给出实测证据**，四期若要复用必须先验。出处：docs/26:101-105；docs/27:16, 27:138。

### D5 比较器与环路

- **何时用环**：次高位 `w_ref ≤ 897` 入普通容器；最高位 `2 w_ref` 超过 897 时**用比较器环**，放最外侧。环数 = 该位的权重个数：`64·#{k: max|U^(k)|>882} + 32·#{k: max|V^(k)|>882}`。条件：b=8 且两层都 w_ref=882 时只有最高位需要环 → 96 个（64+32）。出处：docs/27:34-48；docs/34:36；docs/39:97。
- **环的规律**：每加一个环，`w_ref` 翻倍、`b*` 加 1、误差约减半、`Z` 上界翻倍、Z 位宽 +1。三情形对照：B（0 环, w_ref 441, b*=9, Z 11 位, 5.69%）、A（1 环, 882, 10, 12 位, 3.00%）、C（2 环, 1764, 11, 13 位, 1.64%）。出处：docs/28:11-29, 28:70-76；docs/29:64-74。
- **环该花在层2**：层2 占 84.9% 的误差（n=64 使 √(nb) 大 4 倍，全局 β 又带 2.07 倍放大），所以 64 环（层1=441/层2=1764，2.06%）比 96 环（均匀 882，2.99%）更准，每环改善 0.057 点 vs 0.028 点。条件：只有层2 用双环、层1 用单档时成立。出处：docs/34:44-65, 34:54-57。
- **比较器减法模式自带 0 下截断**，正好等于 CLIP 的下界，所以 `G_p−G_p,min ≥ 0` 减 `B_p > 0` 即使为负也自动截到 0，**不需要额外的符号处理电路**。条件：B_p 恒正（实测 [5279,12142]）。出处：docs/14:136；docs/15:69-71；docs/12:83。
- **min-max 成本标度**：`成本 ∝ log₂(span Z)`，所以每加一个环只多一位。判据：想不改 min-max 就拿精度 → b 从 8 提到 10（4.65%→3.00%，Z 仍 12 位）；想省 min-max → 走 B（11 位，精度退回 5.69%）。出处：docs/29:30, 29:74, 29:89-91。
- **环的体积不可引用旧数**：`96/18432 = 0.5%` 是**个数比，不是体积比**；环的体积模型不存在，所以"代价可忽略"这条结论作废。可用的是"环数与权重数"这一线性项。出处：docs/29:10-19。
- **LUT 阶跃公式（仅 LUT 方案用，四期若回头做 LUT 可查）**：红石粉截断 `Δλ(x) = 15 − b_{x+1}`；比较器截断 `Δλ(x) = (29−x) − b_{x+1}`；反解 `b_{x+1} = 15 − Δf(x)`；`λ_max = 15×897 = 13,455`（16 个容器之和，897 只约束单个容器）。出处：docs/25:24-46。

### D6 三类误差与最优位宽

- **输入量化误差**：`ε_x = δ_x/(2Δ_X) = 2^-(b+1)`。条件：只由 b 决定，与层无关。出处：docs/30:11-17。
- **输出量化误差**：`ε_y = δ_y/(2Δ_Y)`，形式同 2^-(b+1) 但**系统性偏大**：`c_j` 按"可达最大极差"而非实测极差定，`δ_y > Δ_Y/2^b`，实测 b=8 时 0.00253 vs 理论 0.00195（+30%）。条件：只对 ReLU 层显眼；层2 的 ε_y≈3×10⁻⁵，可忽略。出处：docs/30:19-44。
- **权重量化误差**：`ε_w = √(nb/24)/(σ Δ_Y)`，关键是 `σ` 与 b 无关（`σ = W_ref/(max|w|·Δ_X/4)`），所以 `ε_w ∝ √b / W_ref`。**每一位等权**（残差乘的是 0/1 位值，不是 2^k），所以是 √b 而不是等比收敛——权重从 3 到 1764 差 588 倍，逐位贡献 std 全在 0.00030~0.00045。实证：b=6→13 误差涨 1.41~1.51 倍（理论 1.472）。出处：docs/30:48-76；docs/31:29-60；docs/32:180-207。
- **实用 ε_w（数值更准）**：`ε_w^rel ≈ 2/(4W_ref)`，实测误差 ±7%（解析式 √(nb/24)/σ 系统偏高 16~21%）；若要合并两种归一，可用 `√(b/12)/(4W_ref)`。条件：配 `η_rms` 使用。出处：docs/31:68-96。
- **最优位宽定律**：令 `ε_x ≈ ε_w`，忽略 √b 的对数级影响 ⟹ **`b* = round(log₂ W_ref)`**；推论：`W_ref` 翻倍 ⟹ `b*+1`、误差砍半。三段实测完全落在公式上（441→9、882→10、1764→11）。条件：适用于 ReLU 全连接层；**末层不适用**（末层是 min-max + 归并，2^-(b+1) 不成立）。出处：docs/30:80-104；docs/32:209-229, 32:257-260。
- **误差预算（w_ref=882，层1）**：b=8 时 εx 0.00418 / εy 0.00247 / εw 0.00032（εx 主导）；b=10 时 0.00103/0.00066/0.00035（εx 主导 3 倍）；b=11 三者持平（交叉点）；b=13 时 εw 主导。**解析交叉点 11，实测最优 10，差 1 位**——因为逐层局部误差≠端到端、ReLU 截断与 min-max 都未建模。出处：docs/30:110-143；docs/32:233-240。
- **高 b 的第二个惩罚机制（强）**：b 增大使层2 的低位权重掉到 1 以下被取整成 0；b=12 时情形 A 从 3.12% 跳到 4.15%，√b 解释不了。判据：看到"高 b 反而变差"，先查层2 丢位，不要只归因 εw。出处：docs/31:107-113；docs/32:242-248。
- **端到端换算（可用来做成本预测）**：`翻转率 = 0.51×15 ε_z/ρ ≈ 13.8 ε_z`，其中 ρ=0.558 是"实际 span 占满量程比例"（min-max 压缩 1.79 倍）、c=0.51 是骑墙值折扣。实测三个点的比值 14.3/13.7/13.5 极稳。条件：本项目 32 像素 min-max + 16 级；换网络要重测 c 与 ρ。出处：docs/33:38-59。
- **全局缩放的代价可量化**：`r_p = max_j|v_pj|δ_j / max_{p,j}|v_pj|δ_j ∈ (0,1]`，通道 p 的误差被放大 `1/r_p`；`E[1/r_p] ≈ 2.07`（与 b、W_ref 基本无关），代价是 +69% 翻转像素。`E[1/r_p]` 随输出通道数变：m=4→32 时 1.45→2.07（涨 1.43 倍，远慢于 √m）。出处：docs/33:73-109；docs/34:86-102。
- **误差模型的自认边界**：①逐层局部≠端到端（解析高估 1~3 位）；②未建模 ReLU 截断；③未建模 min-max 放大/压缩；④**末层完全不能这么算**；⑤εw 的独立性假设偏乐观（相邻位是同一实数乘 2^k 后取整，误差相关）。引用这些公式时必须带这条。出处：docs/32:250-260。

### D7 网表与成本核算

- **体积系数（三口径互证）**：`V_bits = 3b·2n·2m = 12nmb`，`V_LUT = 4.5·n·(b/4)·m·32 = 36nmb`，比值 3。三条独立校验：容器/权重 4:1、方块³/容器 0.75:1、4×0.75=3；且 LUT 的 9 方块³/容器与一期 `V≈4n·h·L` 反推一致。出处：docs/39:22-39。
- **本项目实算**：数模结合核心 ≈3.0×10⁵ 方块³，LUT 同位宽 ≈8.1×10⁵（比值 2.72）。出处：docs/39:41-48。
- **容器/权重随 b 的交叉点**：位权重 = b 个容器/权重，LUT = 16 个（固定 4 位）或 4b（多位半字节拆分），交叉点 **b=16**；用"误差×容器数"作效率指标，LUT 是位权重的 1.4 倍（本项目 b=10 恰好落在交叉点附近）。出处：docs/37:110-132；docs/38:50-54。
- **误差×体积的取舍结论（39 的判决依据）**：LUT 的权重误差等效 `W_ref≈4×882` 且不需环，但体积 3 倍、容器利用率只有 1/15=6.7%；而精度已不是瓶颈（位权重 2.99% 够用）⟹ **选位权重**。判据：只有当"精度成为瓶颈且无法靠加环解决"时，才回头考虑 LUT。出处：docs/39:52-85；docs/38:116。
- **常数账（灰度，b=8，可直接用于四期同类网表）**：U 2,048；V 16,384；A/c/B 160；β 与 15β 2；合计 18,594。运行期只有**加、减、比较、右移**，没有乘法、没有除法。出处：docs/32:96-105；docs/15:75-86。
- **输出级成本（跳过 Y 之后）**：逐神经元减 A_p（32 次减）+ clip 到 [0,15s]（32 次比较）+ 取 min/max 与 span（1 次 argmax + 1 次减 + 1 次右移）+ `15d` 与除以 span 各最多 15 次连减（合计 30 次）。**没有乘法、没有除法、没有舍入误差源**。出处：docs/11:105-117。
- **末级归一化的判据（floor 必须加半步）**：`level = ⌊(15d + span/2)/span⌋`。条件：不加半步时系统性偏低 −0.494 级、46.7% 像素不同；加半步后 12.2%、偏差 −0.077。实现方式：起始信号取 `2³¹ − span/2` 而不是 `2³¹`（只多一次减法）。出处：docs/10:99-122；docs/11:50-53。
- **抖动层成本**：`n²+1 ≥ 16 ⟹ n_min=4`；每格灯数 n²，灯数 = 每像素格数 × n²。n=16 时 128×128 像素 = **16,384 灯**，抖动误差 0.0273 可忽略。出处：docs/35:30-44；docs/36:14-29。
- **可观测性判据（比面积更硬）**：`D ≳ 340 n p`（≈10 角分），n=4 需 1,360 方块 > MC 渲染距离 512 ⟹ 实地点阵可见；且红石灯对比度仅 **1.75:1**（16 级只差 3.07 亮度单位 ≈2~3 JND）。判据：想提升观感优先换高反差方块对（黑/白混凝土约 27:1，可辨识性 ×4.6），而不是加 n。出处：docs/35:105-128；docs/36:35-56。
- **网表产物**：`results/netlist_grayscale.json`（层1 out=8、层2 out=12），是 39 号修订后唯一的口径基准；`results/final_spec.json` 是投掷器侧定稿参数。出处：docs/39:4-5；docs/25:198-200。
