# 拉伸目标（训练） vs 拉伸后处理（显示）：区别与实验

---

## 一、训练时的"拉伸目标"是怎么做的

在 `dim_sweep.py` 加 `--stretch-targets`，改动只有四行：

```python
TGT = RTRUE.float()                        # 目标灰度级，形状 (N,32)
lo  = TGT.min(1)                           # 每张脸自己的最小值
hi  = TGT.max(1)                           # 每张脸自己的最大值
TGT = (TGT - lo) / (hi - lo) * 15          # 拉伸到铺满 [0,15]
RTRUE = TGT.round().long()                 # 判别器和镜像用整数版
RIMG  = image_from_left_half(RTRUE)        # 重建 8×8 完整图
```

**随后损失照旧**：MSE 对 `TGT`（浮点）+ TV + 对抗。

**关键点**：拉伸的是**训练目标**，不是输出。所以模型学到的"一张脸"在定义上就必须铺满全范围。
实测目标脸的平均跨度从 **11.2 → 14.59**。

结果：发灰率 14.77% → **1.60%**，**0 个冻结像素**（无法作弊）。
代价：它学的是另一套目标，所以不能按原目标的准确率去衡量。

## 二、对比度损失为什么失败（教训）

我同时试了"加对比度损失项"：

$$\mathcal{L} += w\left(\mathrm{std}(\hat y)-\mathrm{std}(y)\right)^2$$

它把发灰率降到 0.33%，看起来好 45 倍。**但那是假的**：

| 变体 | 冻结像素 | 其中纯黑 |
|---|---:|---:|
| dim4 基线 | 0/64 | 0 |
| **dim4 + 对比度损失** | **6/64** | **6** |
| dim4 + 拉伸目标 | 0/64 | 0 |
| dim22 | 0/64 | 0 |
| 真实脸 | 0/64 | 0 |

冻结位置 (0,1)(0,6)(1,1)(1,6)(3,0)(3,7)，**均值 0.00、标准差 0.00**。

**原因**：这一项只惩罚离散度的**大小**，而把两个像素永远钉在 0 是抬高 std 最便宜的办法。
MSE 只损失 2/32，std 项却大幅满足——优化器找到了这个洞。

**这个模型作废，不进打标池。**

## 三、现在做的是"后处理拉伸"（min-max）

对**解码后的 32 个连续灰度值**做变换，权重完全不动：

`
1. lo = min(v),  hi = max(v)        # 这一张脸自己的最暗/最亮输出
2. scale = 15 / (hi - lo)
3. v'[i] = clamp( (v[i] - lo) * scale, 0, 15 )
4. 四舍五入到最近的整数灰度级
`

**例**（四个位置）：raw = [3.2, 5.1, 4.0, 8.9]
- lo=3.2, hi=8.9, span=5.7, scale=2.632
- 3.2 → 0.0
- 5.1 → (5.1−3.2)×2.632 = 5.0
- 4.0 → (4.0−3.2)×2.632 = 2.1
- 8.9 → (8.9−3.2)×2.632 = 15.0

### 性质

| 性质 | 说明 |
|---|---|
| **形状不变** | 是仿射变换，像素之间的相对关系原样保留 |
| **必然满幅** | 最暗位置必为 0、最亮必为 15，所以对比度恒为 15、发灰率 0% |
| **会移动亮度** | 原本跨 [5,8] 的脸会被推到 [0,15] |
| **逐张进行** | 不是按模型，而是每张脸用自己 min/max |
| **无法作弊** | 最小/最大值出现的位置每张都不同（实测 0 个冻结像素） |

**这和训练时的 --stretch-targets 是同一个变换**，只是作用在输出而不是目标上。

### 另一种可选方式 ?stretch=mid

绕脸自己的**中点**缩放，亮度得以保留；但亮度靠边的脸会被裁剪，
实测平均对比度只有 **13.53** 而不是 15。默认不用。

### 实测（走网页自己的代码路径，每臂 1500 张）

| 臂 | 对比度 | 发灰率 | 冻结像素 |
|---|---:|---:|---:|
| dim4 原始 | 8.73 | **18.53%** | 0/32 |
| **dim4x 拉伸后** | **15.00** | **0.00%** | 0/32 |
| dim22 参照 | 12.25 | 0.40% | 0/32 |

## 四、本轮盲测的设计

| 臂 | 说明 |
|---|---|
| `dim4` | PCA-4 原始输出（上一轮良率 45.5%） |
| `dim4x` | **权重完全相同**，只多一个显示拉伸 |
| `dim22` | 参照（上一轮 15.7%） |

**dim4 vs dim4x 是控制变量实验**：模型一模一样，唯一差别是后处理。
所以两者的差异**全部归因于拉伸**。

**dim22 作为锚点**，用来检验本轮的标准是否与上一轮一致。

### 关键：本轮标签单独记账

URL 带 `&round=2`，服务器会把 `round` 写进每条标签。
上一轮 315 张的 `round` 为空，**两轮不会混在一起分析**。
