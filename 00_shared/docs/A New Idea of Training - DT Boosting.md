# 背景

我要提出一种新的减少训练成本的方式。它的主要思想借鉴于LDA和Boosting。

既然查找二值函数表（DDTT）的训练在小规模下很有用，那为什么不把这种有用保留到网络规模亏大之后呢？

主要是因为，多层网络所有的东西都互相耦合，层与层之间要协调，穷举就直接爆炸了，很容易陷入局部最优。

那就试图找出一种方案，每次只前向训练一层中的一个通道。这样节点增加带来的指数效应变成了线性效应。

# 方法

假设有一个计数型的DT网络（求和形式也相仿）：
$$y_i = G_i (\sum_j \boldsymbol{1}(F_{ij}(x_j)))$$
不管它处于多层网络的什么深度，先从最浅层的连接开始训练，先训练第一个$y$，然后依次往后训练。每个$y$训练的目的是，使得输入标签不同的$x$得到的$y$的方差最大。很像LDA，把高维数据投影到使得各自阵营内部方差最小、不同阵营之间方差最大的地方。

这个方案可以和分层粒度训练结合。如果从1反转到2反转，能训练出的$y$的方差等属性没有很好的提高，那么就不需要继续了。否则，继续提高反转数量。

值得一提的是，$G$往往是$D$函数，可以实现两次反转，几乎是信号对称。也就是说，它的函数图像大概是两边高、中间低。那么这意味着需要$y$的方差大，只需要$G$里面的东西在标签不同的时候集中在0~15这个“环”上的两个中心点处。这是因为，既然$D$可以实现两次反转，或者说对称，那么在0~15上，0和15基本上是紧挨着的，它们距离7和8最远。$G$有点像一个周期和相位精心设计的三角函数。

当然，取决于输入数量，计数型的神经网络，第一层的G内部往往只能收到0~输入个数的信号，所以顶不满。这还得仔细设计一下。

当第一个$y$尽力了之后，接下来的$y$重点关注第一个$y$分错的输入，要让这些输入达到异种标签方差最大化。这就有点像Boosting，AdaBoost之类。

这种方案的缺点是，先训练了一层，这样如果很多重要信息在这一层损失了，那后面叠多少层都无益于提高性能。所以要尽量保证这一层信息不损失。宁愿分得不彻底，也不要混淆关键信息。

在后面的层中，这些关键信息还有被利用的机会，同时前面层的输入已经在某种程度上解开了一些复杂的数据耦合，通过这种方法可以把指数增长的训练难度降为线性的。

# 展望

它可以和我们之前提到并测试出来的好方法结合。如果可以缓解DDD和DDDD在模拟求和网络中的训练难度且效果不打折扣，那将是一个壮举。中间节点的数量依然可以是1+2+4+8，怎么分配呢？第一个进行一阶分类，后两个则分别关注第一个分类器犯下的弃真和取伪错误，后面四个分类器分别关注……这是一种方式。也可以让它们层层递进，每个$y$都只负责最保守地不犯取伪错误，感觉是像是每个$y$都在“抠掉”分类中最好分的大块儿，给剩下的通道出更难的题。这样层层的$y$进行或运算，也可以把数据分开，尽可能保留更多信息。
