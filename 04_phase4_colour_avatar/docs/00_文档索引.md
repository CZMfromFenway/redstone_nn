## 3. 整理是怎么做的

1. **并行摘要**：派四个子代理分别精读一期、二期、三期 00~39、以及工具与产物，产出结构化摘要（都在 `_work/digest/`）。
2. **本人复核**：所有关键数字与公式由我直接回读原始文档核对，不采信二手转述。两份成文文档里的每条数字都能在原文找到。
3. **冲突并置**：原始文档互相矛盾时并列呈现并注明出处，不做调和（例：投掷器"每通道 8/10/11 个"三个数、$w_{\text{ref}}$ 的上限 448/897、灰度良率 62.1% vs 66.5%）。
4. **不动原文**：所有原始文档原地保留，只对已过时的索引与 README 做小修补（见 §5）。
