# Dyadic Multi-Granularity Count Layer v0.8

## Proposal
15 hidden/output channels split as 1×K<=1, 2×K<=2, 4×K<=4, 8×K<=8. Hidden G is restricted to single-D-compatible binary predicates (<=2 reversals) in this pilot.

## Mathematical interpretation
This is a heterogeneous multiresolution feature bank. It becomes genuinely boosting-like only if trained stagewise so later groups target residual/hard examples; standard boosting is a forward-stagewise additive model, whereas this Count network has a nonlinear count/D head.

## Function-library sizes per edge
K1=32, K2=242, K4=3882, K8=45638 binary 16-point functions.

## Physical core estimate
Using guaranteed compilers D(depth1) for K<=2, DT(depth2) for K<=4, DDTT(depth4) for K<=8, total row-depth units = 1×1+2×1+4×2+8×4 = 43. Matrix-core volume ~= 8*n*43 = 344n blocks before routing/pre/post-processing.
Homogeneous K4 (15×DT): 240n blocks. Homogeneous K8 (15×DDTT): 480n blocks. Thus terraced mixed-depth core is ~71.7% of homogeneous K8 and ~143.3% of homogeneous K4. If all groups must be padded/aligned to depth4, the volume saving disappears; physical layout must be validated.

## Interpretation
1. The heterogeneous 1/2/4/8 architecture is competitive with homogeneous K4/K8 under the same low-budget trainer, but not decisively better.
2. Naive coarse-to-fine stagewise training is not stably superior. MLP Teacher mean worsened; Count Teacher had similar mean but much larger variance and a notably good best run.
3. All-at-once heterogeneous training used fewer sample-evaluations than homogeneous K8 while achieving similar error, so the architectural prior may reduce search cost.
4. Allocation 1:2:4:8 is not yet proven optimal; preliminary allocation sweep suggests reverse 8:4:2:1 is too simple for Count-native targets.
5. Next training test should use weighted hard-example/residual reweighting for each newly added complexity group rather than merely freezing/growing groups.
