# 1. 实验要回答的问题

> 用强模 LUT 搭出 MLP 的一层，在**同结构、同形状**下，它离一个真实 MLP 有多远？
> 在**红石实际布线的物理约束**下，这个差距会变成多少？靠加宽能否补回来？

# 2. 实验配置

## 2.1 公共部分

| 项 | 设定 |
|---|---|
| 输入空间 | $(x_1,x_2,x_3,x_4)\in\{0,\dots,15\}^4$ |
| 状态总数 | $16^4=65536$，**全部穷举**，无训练/测试划分 |
| 目标标签 | `DT_baseline_recovery/teachers/N4_MLP_T1.npy`（$4\to8\to1$ tanh MLP，seed 71000，正类 18436，SHA-256 已校验） |
| 评价指标 | 全部 65536 状态上的最终 0/1 错误数（`hard MAE` 口径） |

目标标签本身是一个 MLP 的输出，所以"0 错"是该任务的能力上限。

## 2.2 三组对照

| 组 | 说明 | 训练 |
|---|---|---|
| **A 原 Teacher** | $4\to8\to1$ tanh 实数权重，官方前向 | 无 |
| **B 同结构实数 MLP** | $4\to8\to1$ tanh 实数权重 | 在同一批标签上从零训练（numpy 手写反传 + Adam，全批，3 种子取最好） |
| **C 强模 LUT** | 同形状，用强模 LUT 实现 | 无训练，由 A 的权重直接编译 |

## 2.3 强模 LUT 的构造

单个单元要算 $u_j=\sum_i W_{ji}\frac{x_i-7.5}{7.5}+b_j$，$h_j=\tanh(u_j)$。展开成线性式：

$$u_j=\sum_i\frac{W_{ji}}{7.5}x_i-\sum_i W_{ji}+b_j$$

**每个坐标一张 LUT**，直接实现阶梯：

$$\lambda_i(x)=p_i\cdot x,\qquad p_i=\mathrm{round}\!\left(s_j\cdot\frac{|W_{ji}|}{7.5}\right)$$

- 正权重用**反式**（$\lambda$ 为上升阶梯），负权重用**顺式**（下降阶梯）；
- 容器值取常数 $b_t=15+p_i$（$t=1..15$），$b_0=0$；
- 约束：$p_i\le 868$（两种截断交集）、$15+p_i\le897$（容器上限）。

**缩放因子逐神经元独立**：$s_j=\min_i\bigl\lfloor 868\times7.5/|W_{ji}|\bigr\rfloor$。

**阶梯是舍入型**（每步取 $\mathrm{round}(x\,s_j|W_{ji}|/7.5)$ 的差分），不是均一步长；因此每点误差被 $1/(2s_j)$ 咬住，不随 $x$ 累积。

**激活层**是一张一维单调表，输入 $t_j=\sum_i\lambda_i(x_i)$，输出 $\tanh(t_j/s_j-\sum_iW_{ji}+b_j)$。
**关键：激活表存模拟量，不能二值化**（实测二值化会让端到端从 99.99% 掉到 73%）。

## 2.4 第二条实验线：加上物理硬约束

红石布线带来两条硬约束：

> **C1** 比较器不能输出负信号 ⟹ $\lambda_{ij}\ge0$ 处处成立（$B_{ij}$ 要取大）。
> **C2** 神经元是**纵向**输出的，而强模只能在同一水平面内传递 ⟹ 每层的 $y$ **必须转成弱模 $0\sim15$**。

C2 是一个大压缩：隐藏层原本有约 $10^4$ 个不同输出值，现在只剩 16 个。
加上这两条约束后，配置如下：

| 项 | 设定 |
|---|---|
| 参照 A | 原 Teacher（隐藏层连续） |
| 参照 A′ | 原 Teacher 权重不变，只把隐藏层量化到 $0\sim15$ |
| 参照 A″ | A′ 的隐藏编码固定，**只重训输出层** |
| 参照 B | 同结构实数 MLP，隐藏层量化到 $0\sim15$，STE 联合训练 |
| 实验 C | 强模 LUT（$\lambda\ge0$），隐藏层 $y\in\{0..15\}$ |
| 实验 C′ | 同设计，但解除 C2（隐藏层保留模拟量）作上界 |

**输出层的处理**（利用"最终只要 1 bit"这一点）：隐藏值 $h_j$ 本身是 $0\sim15$ 的整数，
输出层直接取 $\mathrm{sign}\bigl(\sum_j v_jh_j-\theta\bigr)$，$v_j,\theta$ 为高精度整数，
**不经过任何 $0\sim15$ 的 $\tanh$ 映射**，因此阈值可以很精细。
实测把 $v,\theta$ 量化到 $10^{-3}$ 与不量化结果完全一致（都是 1256 错）。

# 3. 结果

## 3.1 无约束（隐藏层可传模拟量）

| 方案 | 形状 | 最终错误 | 错误率 |
|---|---|---:|---:|
| A 原 Teacher | $4\to8\to1$ | **0** / 65536 | 0.0000% |
| B 同结构实数 MLP（重训，3 种子最好） | $4\to8\to1$ | 333 / 65536 | 0.5081% |
| **C 强模 LUT** | $4\to8\to1$ | **3** / 65536 | **0.0046%** |

隐藏层模拟量与实数 tanh 的**最大偏差 $6.2\times10^{-4}$**，与理论预期 $1/(2s_j)$ 一致（$s_j\ge2512$）。
C 比 B 更接近目标，因为 C 是从 A 编译来的，而 B 从零训练会受优化噪声影响。
**结论：在没有 C2 的情况下，强模 LUT 对 MLP 的逼近几乎无损。**

## 3.2 加入 C1 + C2

| 方案 | 隐藏层 | 错误 | 错误率 |
|---|---|---:|---:|
| A 原 Teacher（实数，隐藏层连续） | 连续 | **0** | 0.0000% |
| A′ 原 Teacher + 隐藏层量化 + 原 $W_2$ | 0~15 | 18436 | 28.1311% |
| A″ 原 Teacher + 隐藏层量化 + 重训输出层 | 0~15 | 1256 | 1.9165% |
| B 同结构实数 MLP（STE 联合训练） | 0~15 | 942 | 1.4374% |
| C 强模 LUT（$\lambda\ge0$，原 $W_2$ 读出） | 0~15 | 18436 | 28.1311% |
| C-retrain 强模 LUT 隐藏编码 + 重训输出层 | 0~15 | 1256 | 1.9165% |
| C-full 强模 LUT 隐藏层联合重训 + 最优读出 | 0~15 | 1180 | 1.8005% |
| **C′ 强模 LUT，解除 C2** | 连续 | **3** | **0.0046%** |

基线（恒预测多数类）：47100 / 65536 = 71.869%。

三条结论：

1. **C1 没有代价**。$\lambda$ 全部非负（实测范围 $[0,13020]$），容器仍是常数 $883\le897$，步长仍是 868。代价只是 $B$ 取大，而 $B$ 本来就允许超 897。
2. **C2 是决定性的**。同一个设计，隐藏层留模拟量是 3 错，量化到 $0\sim15$ 变成 18436 错（正好等于多数类基线）。
3. **输出层必须重新标定**：$28.13\%\to1.92\%$ 完全来自这一步。原来的 $W_2$ 是为连续 tanh 标定的。
4. **在 C2 下，强模 LUT 与实数 MLP 基本打平**：$1.80\%$ vs $1.44\%$。

A″ 与 C-retrain 的错误数**完全相同（1256）**，说明瓶颈是"8 个 16 级弱模输出的带宽"，
与用什么方式实现无关。

## 3.3 加宽能否补回损失

网络 $4\to h\to1$，隐藏层量化到 16 级，STE 反传，输出层高精度阈值，1500 步 × 2 种子：

| $h$ | 隐藏层量化 0~15 | 隐藏层连续 |
|---:|---:|---:|
| 8 | 971 (1.4816%) | 1139 (1.7380%) |
| 16 | 749 (1.1429%) | 470 (0.7172%) |
| 32 | 662 (1.0101%) | 299 (0.4562%) |
| 64 | 627 (0.9567%) | 191 (0.2914%) |

**加宽有效但收益递减**：$h$ 扩大 8 倍，量化版只从 1.48% 降到 0.96%，而连续版能从 1.74% 降到 0.29%。
说明瓶颈在优化，不在容量——标签本身就是一个"8 单元 × 16 级"的函数，理论上 0 错可达。

## 3.4 换损失 + 教师初始化（2500 步 × 2 种子）

| $h$ | BCE | hinge | **hinge + 教师初始化** |
|---:|---:|---:|---:|
| 16 | 770 (1.1749%) | 753 (1.1490%) | **661 (1.0086%)** |
| 32 | 570 (0.8698%) | 605 (0.9232%) | **425 (0.6485%)** |
| 64 | 508 (0.7751%) | 565 (0.8621%) | **293 (0.4471%)** |

**"先用连续隐藏层的教师初始化，再训练量化网络"效果显著**：$h=64$ 时错误从 0.775% 降到 0.447%，几乎腰斩。
这就是"用离散输出的中间神经元训练 MLP、再反编译回强模 LUT"这条训练路线。

# 4. 结论

1. **单个单元的算术与分辨率不是瓶颈**。无 C2 约束时逼近误差仅 $6\times10^{-4}$，端到端 3/65536。
2. **真正的瓶颈是"每层只能传 4 bit"**（C2）。把隐藏层压到 16 级后，$4\to8\to1$ 的容量不够用
   （A″ 与 C-retrain 同为 1256 错，是架构上限而非实现差异），必须**加宽**或**改用数电纵向传输**。
3. **强模 LUT 与实数 MLP 在同样约束下基本打平**（1.80% vs 1.44%），且 $\lambda\ge0$ 不带来额外代价。
4. **训练路线的关键**是"教师初始化 + 面向量化的微调"：先用连续隐藏层训一个 MLP，
   再以它初始化量化网络并用 hinge/软量化退火微调。纯 BCE + 随机初始化会明显更差。
5. **输出层可以且应当用高精度阈值**：最终只要 1 bit，不必经过 $0\sim15$ 的映射。
